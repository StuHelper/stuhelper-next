# 数据保留与删除

## 保存范围

数据按用途分类保存。每类数据具有保存期限、删除负责人和验证方式；审计、数据库、对象存储、索引与备份使用同一分类。以下为业务实现时的默认设置，法律要求或正在处理的争议使用明确的保留依据和复核日期。

| 数据 | 默认保留与处理 |
| --- | --- |
| 学生认证原始材料 | 审核结束后 30 天清理；本人获准删除时执行对应资料删除 |
| 学生资格和学习经历结论 | 按有效资格与账号业务周期保存，撤销、删除按认证规格执行 |
| 一次性学校认证任务的密码与临时会话 | 任务内使用，任务结束销毁，最长存活 15 分钟；不用于限制另行授权的长期存储托管 |
| 长期存储托管凭据 | 经账号拥有者明确授权，在托管授权有效期间保存；到期、撤回或替换后停止使用并清理，业务记录只保存凭据引用 |
| 存储供应商会话与续期材料 | 按供应商实际有效期和托管授权范围管理，失效后续期或重新登录；授权终止立即停用，不沿用临时学校认证的 15 分钟上限 |
| 导入临时文件 | 处理完成后 24 小时清理，已归档的业务映射保留来源标识 |
| 撤回重编草稿及整条讨论 | 撤回成功后保留 24 小时，到期永久删除正文、版本、回复和投票 |
| 已主动删除的评价讨论 | 删除成功后业务存储清除内容，检索和缓存同步失效 |
| 上传临时对象 | 24 小时内建立有效引用，过期未引用对象清理 |
| 群消息处理证据 | 默认 30 天，按获准的群消息功能配置范围 |
| 敏感字段查看与管理审计 | 默认 12 个月，访问按独立审计权限管理 |
| 运行安全日志 | 默认 6 个自然月，日志字段经过脱敏 |
| 导出文件 | 默认 24 小时，访问同时检查操作者和原授权范围 |
| 幂等响应 | 完成后 24 小时；业务唯一键依所属业务事实保留 |
| outbox/inbox 投递详情 | 完成后 90 天；去重标识与业务唯一性按事件类型保存 |
| 订单、账本与权益依据 | 基础业务记录默认至少 3 年；履约、争议及适用法定期限仍未结束时继续保留 |
| 收藏和收藏夹 | 按账号业务周期保存，业务账号注销时删除，包含名称快照和幂等响应；favorites 负责删除，以归属、并发及恢复测试验证 |
| 已注销账号投票 | 随评价讨论匿名保留并继续统计，讨论删除时一并清理；reviews 清除账号关联、回执及投票审计中的账号，以统计数量准确和不可反查测试验证 |
| 注销申请、进度及步骤 | 未完成时保存至人工处理完成，完成记录保留 12 个月；profiles 负责保留与删除，以重启恢复、当前管理员权限及幂等测试验证 |
| 账号关闭标记 | 账号生命周期内保留最小身份绑定和关闭事实，防止重建及恢复旧数据；所属模块负责，恢复演练检查标记仍生效 |
| 收藏操作事件 | 保留 12 个月，favorites 负责删除，清理任务与恢复验证须核对截止时间及其他账号隔离 |
| 模块安装历史 | 随部署数据生命周期保存，平台与部署维护人负责，不能通过关闭配置删除；以重启、数据库故障和未知状态测试验证 |
| 开放平台应用及逐项授权 | 应用和用户业务关系存续时保存当前审批与授权，终止后保留 12 个月审计依据；open-platform 负责归档与删除，以撤回、注销和恢复测试验证 |
| 开放平台授权请求及授权码哈希 | 授权请求过期 24 小时后清理，最长覆盖已签发令牌的有效期；open-platform 负责，以过期及重放测试验证 |
| 开放平台访问令牌哈希 | 到期后清理，重放时撤销对应令牌；open-platform 负责，验证有效令牌保留、过期删除及其他应用隔离 |
| 开放平台幂等响应 | 完成后 24 小时清理，业务唯一键保留；open-platform 负责，以清理上限、失败回滚和重复执行测试验证 |
| 开放平台通知和审计事件 | 保留 12 个月，第三方回报只表示声明；open-platform 负责，验证有界删除、未到期记录及清理失败恢复 |
| 开放平台日配额 | 保留当前和前一 UTC 日期，open-platform 负责，按数据库原子配额和清理测试验证 |
| 资格配置及修改审计 | 当前配置随部署保存，幂等响应 24 小时、修改审计 12 个月；platform 负责，后台有界清理到期记录，并验证修订冲突与原子持久化 |
| QQ 绑定及挑战 | 当前绑定按账号周期保存，解绑删除相应身份，注销删除三项；未使用挑战到期清理，已使用摘要保留 24 小时，幂等响应 24 小时，限流记录 1 天，审计和已投递事件 12 个月；未确认投递事件保留 |
| 常规备份 | 最长 30 天，按类别加密和访问控制 |

财务凭证、身份材料等涉及特别法定期限的类别，由所属模块在启用真实业务前确定适用依据和具体期限。保留规则不改变积分、权益和资金事实的业务含义。

长期托管可以使用获准保存的 BHpan 账号密码、专用令牌或其他存储凭据。若 BHpan 登录依赖学校统一认证密码，授权必须明确包含该密码的托管与仅用于 BHpan 重新登录，不能从一次性学校认证推定授权。

长期凭据只进入获准私有环境的秘密凭据库，加密密钥与密文分开管理。接口、业务数据库、仓库、日志与审计不返回凭据原文。撤销标记须先于任何恢复后的凭据读取生效，备份按本规格到期清理。

凭据保存期限、供应商会话寿命和验证观察窗口分别记录。15 分钟是一次性认证的项目默认值；24 小时等观察窗口是测试安排，均不代表 BHpan 声明的技术限制。

## 删除流程

删除操作保存最小任务标识、对象标识、删除范围和完成状态。任务记录用于幂等清理与恢复后的再次删除，独立权限，并在常规备份保留期结束后清理无继续用途的标识。

评价删除覆盖整条讨论的正文、版本、回复和投票。关联文件取消引用，media 清理无其他业务引用的对象。外部展示、搜索和缓存立即停止返回已删除内容。清理任务每分钟执行，到期内容在清理完成前不可访问。

备份按既定期限整体到期，恢复流程先应用已确认删除任务和到期规则，再开放服务。删除内容的备份保留上界为 30 天。数据迁移和恢复验证包括这一步，业务切换后的新写入保留。

## 检查与例外

删除任务监控积压、失败和最早到期时间。错误保留脱敏原因码并重试。法律或争议保留由有权人员记录依据、范围、结束条件和复核日期，范围内的数据使用专门访问权限。

| 场景 | 预期结果 |
| --- | --- |
| RET-01 | 撤回草稿满 24 小时后，全部业务读取不可访问，整条讨论清理 |
| RET-02 | 恢复含旧评价的备份时，开放服务前重新执行删除范围 |
| RET-03 | 审核材料到期后，资格结论保留而原始材料被清理 |
| RET-04 | 导出文件到期或请求者失去权限时，下载被拒绝 |
| RET-05 | 清理失败时，监控显示积压，重复执行遵循幂等约束 |

个人信息保存依据包括[《个人信息保护法》第十九条](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2022/art_04a0f1fb5df244e39688fd5372623a8d.html)的必要期限原则。具体类别与运营主体的法定要求由对应业务上线前核对。

新增类别的期限与实现进度分开记录。开放平台已实现请求、令牌、幂等响应、事件、通知与日配额清理；应用及授权终止后的归档、收藏事件和注销历史的到期清理仍待实施，不把期限约定当作已执行删除的证据。
