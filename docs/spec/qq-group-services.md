# QQ 绑定、入群认证与群聊管理

## 范围

保留 QQ 绑定、入群认证、群名片、提醒、黑名单和群消息管理。机器人业务按“群聊管理”“信息查询”“娱乐功能”三个菜单组织。

“群聊管理”包含成员处置、警告、禁言与解禁、关键词、防复读、防撤回、撤回消息查询、举报及 AI 分析。跨全站关联记录放在[信息查询](information-query.md)，骰子和自助禁言放在[娱乐功能](bot-entertainment.md)。QQ 绑定仍可从个人中心进入。

## QQ 绑定与入群

用户把 QQ 与 StuHelper 账号关联，查看绑定结果；入群流程通过这项关联检查用户是否满足目标群要求。需要补充认证时，引导到独立学生认证入口；已有符合条件的资格不要求为每次入群重新完成认证。

管理员能够查看入群申请与处理进度。每个群可选择先认证后批准入群，或先入群并禁言、限时完成认证。学校范围、是否接受校友与临时新生、认证期限和提醒频率均可配置。

另保留群公告动态口令模式。此模式可以用于不要求学生认证的群，成员入群后按公告提交动态口令，提示、时限和开关可配置，超时按该群规则处理。口令验证与学生认证分别判断，不能把口令通过记成具备有效校园资格。

## 聊天工作台与事件订阅

获授权管理员可以查看获准群的实时消息、图片和成员，在聊天工作台发送、转发与撤回消息。读取和发送分别授权，群消息操作仍受平台实际能力及当前权限限制。界面显示实际发送或撤回结果。

群事件订阅支持指定来源群和获准接收目标，订阅处置结果、禁言到期等事件，并可按目标启停。某个目标投递失败不伪造为其他目标已经失败或成功，各目标分别显示结果。这些入口归入群聊管理。

## 资格失效后的处理

发现学生资格失效后，提醒成员补认证，并给予群管理员配置的宽限期。管理员可在此期间延长或豁免。期限届满仍不符合要求且未获豁免时，自动移出群。

普通认证不会按年度到期，毕业也不自动取消平台基础资格。群是否接受校友或临时新生，按该群规则判断。

补认证后满足群要求的成员不再因该次资格失效被移出。管理员查看成员当前处理阶段，能够区分已提醒、宽限期内、已恢复、已延长、已豁免和已移出。资格撤销由[认证管理流程](student-verification.md)处理，用户不能通过自行撤销或删除资格直接触发该业务。

## 群管理能力

群名片使用可配置模板，可引用获准取得的学校、年级、院系、姓名、学号与性别字段，并保留自由昵称。模板支持按字段值选择分隔符，例如男性用 `-`、女性用 `+`。性别未知时采用中性格式，不从姓名、头像或昵称推断。

检查、自动修改、提醒和处罚分别设置开关。初始只检查和提醒，自动踢出与拉黑关闭。所需资料尚未就绪时不算名片违规。管理员可以查看检查结果及例外。黑名单支持单群、指定多群与全平台三个范围。群管理员只能管理获授权的群，全平台限制由平台管理员设置。拉黑必须填写原因，默认永久，也可设置到期日或人工解除。解除后允许重新申请入群，不自动加回。

名片不合规与学生资格失效是两种不同原因。资格失效的自动移出规则不自动扩展成“名片不合规也踢出”或其他未确认处罚。

## 消息、举报与成员处置

| 功能 | 已确认范围 |
| --- | --- |
| 警告与禁言 | 查看成员警告，执行警告、禁言和解禁，查看处理结果 |
| 关键词与防复读 | 配置和检查关键词、重复消息等群规则，查看命中记录 |
| 防撤回与查询 | 按群设置留存，仅获授权的群管理员和平台管理员查看，不自动向群内重发 |
| 举报 | 查看举报对象、原因和相关消息，决定处理方式并反馈结果 |
| AI 举报分析 | 分析举报及相关消息，给出分析结果和处置建议 |

管理员在群聊管理中查看当前群、成员和处理进度。界面区分建议、待执行与实际执行结果。关键词、广告与链接检测、发送频率、防复读、警告累计、禁言时长和 AI 处置规则均可配置。保留观察名单与启用前的规则命中预览，预览不执行实际处罚。

AI 初始可按已启用规则自动警告、撤回或禁言，踢出与拉黑默认交管理员确认。有相应配置权限的管理员也可在管理范围内显式启用自动踢出与自动拉黑，查看规则、适用范围、触发原因和执行结果。AI 分析本身不能越过未启用的动作与管理员权限。资格超时的自动移出继续使用独立准入规则。

## 消息证据与批量管理

撤回消息与举报图片仅供获授权的群管理员和平台管理员查看。留存期限由后台配置，未配置时不启用留存，超过期限删除内容并保留必要的处置记录。查看撤回内容不建立单独的业务查看记录或审计记录，技术日志中也不写入撤回正文。

保留欢迎提示、群规则模板、批量操作与历史成员资格检查。批量处置先预览对象和影响，执行后逐人显示成功或失败。历史成员使用相同准入规则，继续保留管理员已授予的延期与豁免。执行失败应说明当前结果和后续可执行动作，不能显示为已完成处罚。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| QQ-01：用户完成 QQ 关联后申请入群 | 按目标群要求判断，能查看进度 |
| QQ-02：缺少目标群所需学生资格 | 引导补充认证，不伪报已经满足群要求 |
| QQ-03：成员资格失效，仍在宽限期 | 提醒并显示期限，不提前自动移出 |
| QQ-04：期限前重新认证通过 | 取消该次待移出处理 |
| QQ-05：管理员延长或豁免 | 后续判断采用新期限或豁免状态 |
| QQ-06：期限届满、资格仍不满足且无豁免 | 自动移出，管理员可查看处理结果 |
| QQ-07：只发现群名片不合规 | 执行名片规则，不擅自套用资格失效移出流程 |
| QQ-08：管理员查看关键词、防复读或举报记录 | 能识别相关群、成员、消息和处理结果 |
| QQ-09：AI 返回处置建议 | 展示分析和建议，后续执行遵循已批准的群规则 |
| QQ-10：查找撤回消息、用户全站记录或骰子设置 | 三类功能分别位于群聊管理、信息查询和娱乐功能 |

## 配置与后续事项

上述业务规则已确认。认证宽限期、提醒、警告、禁言与重复消息阈值等数值由后台配置，动作资格按全站及授权范围规则管理。尚未配置的自动规则不执行，界面明确显示未启用。
