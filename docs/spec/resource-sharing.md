# 资料共享与访问权益

## 范围

资料包括往年题、笔记、讲义等学习内容，可关联课程，并按需要关联学期、开课和教师。本文记录已确认的目标业务；尚未实现资料 API、管理界面或支付解锁。

## 资料发现与维护

资料有标题、描述、标签和版本。用户可按关键词、标签及相关课程查找，从课程详情进入资料列表，查看资料信息和版本，下载自己有权访问的内容。学校、年份或教师不明确时保留未知，不为补全筛选字段而编造关联。

上传者可以在“我的资料”中查看上传结果，编辑、更正资料，提交后续版本，或提出下架申请。资料不提供普通删除功能；下架申请由管理员处理，并向申请人反馈结果。申请提交本身不代表资料已经下架。

发布资料需已绑定手机号。上传者是否必须同时具有学生资格、文件限制、审核方式和版本发布细节仍待确认。

## 原创与转载

| 选择 | 用户填写 | 业务含义 |
| --- | --- | --- |
| 我的原创 | 无须填写来源，提交前展示简短授权说明及完整条款入口 | 用户就其有权授权的作品授予平台约定使用权 |
| 转载，知道来源 | 一个自由文本框，可填网址、作者或“某某老师的讲义”等文字 | 保存来源说明，不要求用户选择复杂许可证 |
| 转载，来源未知 | 选择来源未知，无须编造出处 | 记录来源尚不明确，允许以后更正 |

转载来源说明本身不产生版权授权，不能把转载资料自动归入原创授权。平台使用范围取决于原权利人的许可或其他合法依据。

## 已确认的原创授权政策

采用全球、免费、非独占的广泛使用许可，作者保留自己的著作权。授权包括复制、存储、展示、传播、翻印、汇编、改编、翻译，以及商业使用和向第三方再授权。授权有效期覆盖有关著作财产权的全部法定保护期及依法延长期间。

参考知乎式授权存续规则：用户要求撤回、资料被下架或删除、账号注销，不当然撤销已有效授予的平台许可。平台仍可在授权范围内开展后续商业使用和再授权，不采用“普通删除后停止所有新增用途”的方案。

下架申请处理与版权许可存续分别判断；授权存续不意味着必须始终公开原资料。依法需要停止使用或处理侵权、个人信息等事项时，按照相应要求处理。上传者实际没有的权利不能通过声明获得，署名等权利也不能笼统写成全部归平台。

上传界面用短说明直接提示商业使用、再授权及授权持续有效，完整文本另行定稿。本文是已确认的业务政策，不是已经上线的用户合同。平台奖励上传者的规则由[积分与余额规格](wallet-and-points.md)定义，不把每次下载消费自动认定为向作者支付版税。

## 下载条件与授权来源

公开资料供已认证学生免费下载。受限资料按有效访问权判断，以下来源任一满足即可访问；同一用户同时满足多项，不重复收费。

| 访问权来源 | 已确认行为 |
| --- | --- |
| 管理员 | 在本人管理范围内访问；不是任意后台角色均可下载所有资料 |
| 单独授权 | 管理员可给指定用户授予指定资料的访问权 |
| 群体权益 | 会员或其他特权群体按配置覆盖指定资料范围，不默认所有会员均可访问全部资料 |
| 解锁购买 | 用户按资料当前规则消费积分或余额后取得该资料访问权 |

资料可由管理员设为仅积分、仅余额或两者二选一的价格。用户已有其他有效访问权时直接下载，不要求再次支付。一次解锁长期有效并包含该资料后续版本，重复下载或更新版本不再次扣费。两种账户、积分购买和退款行为见[积分与余额](wallet-and-points.md)。

## 管理界面

管理员能够在自己的管理范围内查看资料，设置公开或受限访问，设置解锁方式和价格，为指定用户授予或撤回资料访问权，配置会员及其他群体覆盖的资料范围，并查看当前授权来源。批量规则或新的管理角色不在本次默认增加。

下架申请列表展示申请资料、原因和处理状态；管理员处理后反馈结果。涉及已购用户的交付或退款，联动[退款规则](wallet-and-points.md)，不能只下架后忽略已经收取的费用。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| RS-01：选择转载并填写老师姓名，或选择来源未知 | 可以表达来源，不强制填写网址或复杂许可证 |
| RS-02：原创上传者提出下架申请 | 进入处理流程，未自动撤销平台作品许可 |
| RS-03：已认证学生下载公开资料 | 免费下载 |
| RS-04：管理员只管理某个资料范围 | 仅该范围内具备管理员访问权 |
| RS-05：用户已获单独授权，又属于有权益的群体 | 直接访问，不因存在多个授权来源而重复扣费 |
| RS-06：会员权益未覆盖某份受限资料 | 不能仅凭会员名称取得该资料访问权 |
| RS-07：已解锁资料发布新版本 | 已购用户继续下载，不再次收费 |
| RS-08：资料发生普通下架或账号注销 | 不当然撤销已授予的作品许可；实际可下载性按内容处理结果判断 |

## 待确认事项

受限资料是否额外要求有效学生资格、上传资格、管理员管理范围如何分配、直接授权的期限、会员套餐、资料下架后的具体展示与已购交付处理、版权投诉流程和最终协议文本仍需分别确定。配置可以支持的能力不代表具体价格、群体权益或条款已经上线。
