# 资料共享与访问权益

## 范围

资料包括往年题、笔记和讲义等学习内容，可以关联课程、学期、开课和教师。本文说明资料维护、作品授权、下载条件和管理操作。

## 资料发现与维护

资料有标题、描述、标签和版本。用户可按关键词、标签及相关课程查找，从课程详情进入资料列表，查看资料信息和版本，下载自己有权访问的内容。学校、年份或教师不明确时保留未知，不为补全筛选字段而编造关联。

上传者可以在“我的资料”中查看上传结果，编辑、更正资料，提交后续版本，或提出下架申请。资料不提供普通删除功能；下架申请由管理员处理，并向申请人反馈结果。申请提交本身不代表资料已经下架。

上传的初始资格为登录、有效校园资格和已绑定手机号，不额外要求独立实名。管理员可以在管理范围内上传和维护资料。所有动作资格按[资格配置](action-eligibility.md)调整，例如以后为上传追加实名要求。

首次上传、标题与简介等元数据更正，以及新文件版本默认先审核。审核期间继续展示和下载原可用版本。新版本通过后，普通用户只看到和下载新版本，不提供历史版本选择入口。管理员可以因侵权、错误或安全问题停用某个版本。

保留用户上传文件的原始文件名。允许的文件类型和大小由上传配置管理，具体初始设置在上线配置中确定。

上传过程支持取消和失败后重试。取消结果尚未确认时显示处理中，网络异常不能直接显示取消成功。若文件已完成提交，保留实际结果并引导查看我的资料，后续按更正或下架申请处理，不自动重传。

## 原创与转载

| 选择 | 用户填写 | 业务含义 |
| --- | --- | --- |
| 我的原创 | 无须填写来源，提交前展示简短授权说明及完整条款入口 | 用户就其有权授权的作品授予平台约定使用权 |
| 转载，知道来源 | 一个自由文本框，可填网址、作者或“某某老师的讲义”等文字 | 保存来源说明，不要求用户选择复杂许可证 |
| 转载，来源未知 | 选择来源未知，无须编造出处 | 记录来源尚不明确，允许以后更正 |

转载资料记录已知作者、来源和适用许可。存在明确许可时，展示原许可，按其署名、商业使用、改作和再分发条件处理；需要原许可全文或指定声明时随资料保留。转载资料的原创授权字段保持为空。署名与提供来源并不自动获得再分发许可，许可范围依据[《著作权法》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)和实际授权判断。

来源未知的资料可以上传并分发，来源字段明确保存“未知”，后续可补充更正。来源未知仅描述来源状态，平台取得的使用权仍取决于实际权利与适用法律。资料继续适用内容审核及投诉处理流程。

## 已确认的原创授权政策

采用全球、免费、非独占的广泛使用许可，作者保留自己的著作权。授权包括复制、存储、展示、传播、翻印、汇编、改编、翻译，以及商业使用和向第三方再授权。授权有效期覆盖有关著作财产权的全部法定保护期及依法延长期间。

参考知乎的授权存续规则：平台已取得的有效许可在用户要求撤回、资料下架或删除、账号注销后继续有效。平台可在许可范围内开展后续商业使用和再授权。

管理员分别处理资料是否公开和作品许可是否继续有效。例如原资料可以下架，平台已经取得的许可仍按条款执行。涉及侵权、个人信息或法律要求停止使用时，按相应规定处理。授权限于上传者实际拥有的权利，作者的署名等权利继续受到保护。

上传界面用短说明提示商业使用、再授权及许可持续有效，完整用户条款另行定稿。上传者奖励按照[积分与余额规格](wallet-and-points.md)单独计算。

## 下载条件与授权来源

初始规则为公开资料供已认证用户免费下载，受限资料同时要求有效校园资格和至少一种有效访问权。购买、单独授权和会员权益默认不豁免校园资格，管理员在管理范围内例外。身份条件可通过动作资格配置调整，访问权按下表判断。

有效校园资格包含普通认证、已认证校友和有效期内的临时新生，定义见[认证规格](student-verification.md)。普通认证长期有效，毕业本身不会中止资料访问。

以下授权来源用于判断访问权，同一用户同时满足多项不重复收费；管理员范围之外的资料仍按普通用户条件判断。

| 访问权来源 | 已确认行为 |
| --- | --- |
| 管理员 | 在本人管理范围内访问；不是任意后台角色均可下载所有资料 |
| 单独授权 | 管理员可授予指定用户访问权，默认长期有效，也可设置到期日 |
| 群体权益 | 会员或其他特权群体按配置覆盖指定资料范围，不默认所有会员均可访问全部资料 |
| 解锁购买 | 用户按资料当前规则消费积分或余额后取得该资料访问权 |

资料页面展示当前可用的访问方式和账务服务返回的价格。已有有效访问权的用户不重复收费，资格暂时不满足时保留既有权益，恢复后重新检查下载条件。

单独授权撤回或到期只影响该来源，其他有效权益保留。会员、购买、续费和退款的完整业务规则迁至[私有账务规格](https://github.com/StuHelper/stuhelper-billing/blob/develop/docs/spec/resource-entitlements.md)。公开资源模块只使用所需的交易状态和权益结论。

## 下架与投诉

普通下架停止新购买，已购用户仍可按当前资格和访问条件下载。涉及侵权、安全问题或平台无法继续提供文件时，停止全部下载，由管理员处理补发、用户同意的替代交付或退款。

资料详情和站点入口提供侵权投诉。投诉人填写联系方式、目标资料、权利或授权证明及侵权说明。平台登记通知、处理时点和决定；收到符合要求的通知或发现明确侵权事实后，及时采取删除、屏蔽或断开链接等措施，并通知上传者。

上传者可以补充授权依据或提出异议，管理员依据通知、证据和适用规则处理恢复或继续下架。投诉正文与身份证明按权限保存，对外反馈处理状态。投诉造成停止下载时，同时处理已购交付与相应退款。处理流程在运营启用前完成入口和响应演练。

## 目录与批量下载

资料支持学校与课程下的多级目录，由管理员整理，上传者可建议位置。文件类型、单文件与单次容量、目录层级和分包大小均由后台配置，上传前显示支持的格式，未配置的上传或打包能力不开放。用户可以下载整个目录。目录包含多个下载包时，页面列出完整包列表，说明需要下载哪些包才能获得完整目录，并提供逐包下载入口。

目录下载只打包当前有权访问的资料，入口使用“下载可访问资料”等准确说明。页面展示实际包含的内容和下载包，不展示无权项目的缺项列表。多包下载显示本次生成的完整包列表，支持单包重试，重新下载不重复收费。

## 管理界面

管理员能够在自己的管理范围内查看资料，设置公开或受限访问，设置解锁方式和价格，为指定用户授予或撤回资料访问权，配置会员及其他群体覆盖的资料范围，并查看当前授权来源。批量规则或新的管理角色不在本次默认增加。

下架申请列表展示申请资料、原因和处理状态；管理员处理后反馈结果。涉及已购用户的交付或退款，联动[退款规则](wallet-and-points.md)，不能只下架后忽略已经收取的费用。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| RS-01：选择转载并填写老师姓名，或选择来源未知 | 可以表达来源，不强制填写网址或复杂许可证 |
| RS-02：原创上传者提出下架申请 | 进入处理流程，未自动撤销平台作品许可 |
| RS-03：具备有效校园资格的用户下载公开资料 | 免费下载 |
| RS-04：管理员只管理某个资料范围，尚无有效校园资格 | 仅该范围内可按管理员身份访问，不能访问范围外受限资料 |
| RS-05：有有效校园资格的用户已获单独授权，又属于有权益的群体 | 直接访问，不因存在多个授权来源而重复扣费 |
| RS-06：会员权益未覆盖某份受限资料 | 不能仅凭会员名称取得该资料访问权 |
| RS-07：已解锁资料发布新版本，用户仍满足下载条件 | 已购用户继续下载，不再次收费 |
| RS-08：资料发生普通下架或账号注销 | 不当然撤销已授予的作品许可；实际可下载性按内容处理结果判断 |
| RS-09：普通用户已购买、获授权或有会员权益，但学生资格失效 | 暂停下载，授权来源不能豁免学生资格 |
| RS-10：已购用户恢复有效校园资格，资料仍可下载 | 继续使用原解锁权益，不再次收费 |
| RS-11：课程目录由多个下载包组成 | 展示完整包列表和逐包入口，能识别未取得的包 |
| RS-12：上传者尚未独立实名，但满足初始上传条件 | 可以提交；管理员追加实名条件后，后续提交按新条件判断 |
| RS-13：新版本等待审核 | 旧版本保持可用；通过后普通用户只看到和下载新版本 |
| RS-14：直接授权到期，但用户已单独购买资料 | 购买权益保留，不因直接授权到期失效 |
| RS-15：会员到期 | 仅结束会员来源权益，其他有效授权保留 |
| RS-16：资料普通下架 | 停止新购买，已购用户按当前访问条件继续下载 |
| RS-17：资料因侵权、安全或无法继续提供文件而停止下载 | 已购用户进入补发、经同意的替代交付或退款处理 |
| RS-18：目录混有用户无权访问的资料 | 只打包有权内容，展示实际下载包，不列缺项 |

## 配置与后续事项

管理角色遵循[后台配置规格](admin-operations.md)，最终用户协议由项目负责人明确留到上线前单独定稿。交易与会员的具体规则由私有账务模块维护。
