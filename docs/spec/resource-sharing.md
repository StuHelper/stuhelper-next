# 资料共享与访问权益

## 范围

资料包括往年题、笔记和讲义等学习内容，可以关联课程、学期、开课和教师。本文说明资料维护、作品授权、下载条件和管理操作。

## 资料发现与维护

资料有标题、描述、标签和版本。用户可按关键词、标签及相关课程查找，从课程详情进入资料列表，查看资料信息和版本，下载自己有权访问的内容。学校、年份或教师不明确时保留未知，不为补全筛选字段而编造关联。

上传者可以在“我的资料”中查看上传结果，编辑、更正资料，提交后续版本，或提出下架申请。资料不提供普通删除功能；下架申请由管理员处理，并向申请人反馈结果。申请提交本身不代表资料已经下架。

发布资料需已绑定手机号。上传者是否必须同时具有学生资格、文件限制、审核方式和版本发布细节仍待确认。

## 原创与转载

| 选择 | 用户填写 | 业务含义 |
| --- | --- | --- |
| 我的原创 | 无须填写来源，提交前展示简短授权说明及完整条款入口 | 用户就其有权授权的作品授予平台约定使用权 |
| 转载，知道来源 | 一个自由文本框，可填网址、作者或“某某老师的讲义”等文字 | 保存来源说明，不要求用户选择复杂许可证 |
| 转载，来源未知 | 选择来源未知，无须编造出处 | 记录来源尚不明确，允许以后更正 |

转载来源说明本身不产生版权授权，不能把转载资料自动归入原创授权。平台使用范围取决于原权利人的许可或其他合法依据。

## 已确认的原创授权政策

采用全球、免费、非独占的广泛使用许可，作者保留自己的著作权。授权包括复制、存储、展示、传播、翻印、汇编、改编、翻译，以及商业使用和向第三方再授权。授权有效期覆盖有关著作财产权的全部法定保护期及依法延长期间。

参考知乎的授权存续规则：平台已取得的有效许可在用户要求撤回、资料下架或删除、账号注销后继续有效。平台可在许可范围内开展后续商业使用和再授权。

管理员分别处理资料是否公开和作品许可是否继续有效。例如原资料可以下架，平台已经取得的许可仍按条款执行。涉及侵权、个人信息或法律要求停止使用时，按相应规定处理。授权限于上传者实际拥有的权利，作者的署名等权利继续受到保护。

上传界面用短说明提示商业使用、再授权及许可持续有效，完整用户条款另行定稿。上传者奖励按照[积分与余额规格](wallet-and-points.md)单独计算。

## 下载条件与授权来源

公开资料供已认证学生免费下载。普通用户访问受限资料，需要同时满足“有效学生资格”和“至少一种有效访问权”；购买解锁、单独授权、会员或其他特权群体权益都不豁免学生资格。管理员仅在本人管理范围内不受学生资格要求限制。

以下授权来源用于判断访问权，同一用户同时满足多项不重复收费；管理员范围之外的资料仍按普通用户条件判断。

| 访问权来源 | 已确认行为 |
| --- | --- |
| 管理员 | 在本人管理范围内访问；不是任意后台角色均可下载所有资料 |
| 单独授权 | 管理员可给指定用户授予指定资料的访问权 |
| 群体权益 | 会员或其他特权群体按配置覆盖指定资料范围，不默认所有会员均可访问全部资料 |
| 解锁购买 | 用户按资料当前规则消费积分或余额后取得该资料访问权 |

资料可由管理员设为仅积分、仅 Ivory 余额或两者二选一的价格。用户符合当前学生资格要求且已有有效访问权时直接下载，不要求再次支付。一次解锁的权益长期有效并包含该资料后续版本；资格失效时暂停普通用户下载，保留解锁权益，恢复资格后不再次收费。两种账户、积分购买和退款行为见[积分与 Ivory](wallet-and-points.md)。

## 目录与批量下载

资料支持按课程等关联组织目录，用户可以下载整个目录。目录包含多个下载包时，页面列出完整包列表，说明需要下载哪些包才能获得完整目录，并提供逐包下载入口。

整目录下载遵循单份资料的学生资格和访问权要求。目录中包含用户无权下载的资料时，打包范围和提示方式需要单独确定。下载界面显示各包的结果，让用户能识别缺失或失败的部分。

## 管理界面

管理员能够在自己的管理范围内查看资料，设置公开或受限访问，设置解锁方式和价格，为指定用户授予或撤回资料访问权，配置会员及其他群体覆盖的资料范围，并查看当前授权来源。批量规则或新的管理角色不在本次默认增加。

下架申请列表展示申请资料、原因和处理状态；管理员处理后反馈结果。涉及已购用户的交付或退款，联动[退款规则](wallet-and-points.md)，不能只下架后忽略已经收取的费用。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| RS-01：选择转载并填写老师姓名，或选择来源未知 | 可以表达来源，不强制填写网址或复杂许可证 |
| RS-02：原创上传者提出下架申请 | 进入处理流程，未自动撤销平台作品许可 |
| RS-03：已认证学生下载公开资料 | 免费下载 |
| RS-04：管理员只管理某个资料范围，尚无有效学生资格 | 仅该范围内可按管理员身份访问，不能访问范围外受限资料 |
| RS-05：有有效学生资格的用户已获单独授权，又属于有权益的群体 | 直接访问，不因存在多个授权来源而重复扣费 |
| RS-06：会员权益未覆盖某份受限资料 | 不能仅凭会员名称取得该资料访问权 |
| RS-07：已解锁资料发布新版本，用户仍满足下载条件 | 已购用户继续下载，不再次收费 |
| RS-08：资料发生普通下架或账号注销 | 不当然撤销已授予的作品许可；实际可下载性按内容处理结果判断 |
| RS-09：普通用户已购买、获授权或有会员权益，但学生资格失效 | 暂停下载，授权来源不能豁免学生资格 |
| RS-10：已购用户恢复有效学生资格，资料仍可下载 | 继续使用原解锁权益，不再次收费 |
| RS-11：课程目录由多个下载包组成 | 展示完整包列表和逐包入口，能识别未取得的包 |

## 待确认事项

上传资格、管理员管理范围、直接授权的期限、会员套餐、下架后的已购交付、版权投诉流程和最终协议文本仍需分别确定。未认证预购、资格失效后的退款、目录混有受限资料时的打包方式，以及包大小和失败恢复体验也需要确认。
