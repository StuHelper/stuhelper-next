# 机器人娱乐功能

## 范围

娱乐功能作为独立菜单保留，包括掷骰子、自助禁言等旧机器人娱乐命令。与群聊管理中的违规处罚分开，也不放入信息查询菜单；首期保留骰子和自助禁言。

## 用户与管理员体验

用户主动调用已经开放的娱乐命令，能够知道命令用途和实际结果。掷骰子返回该次结果；自助禁言按选定玩法对发起者处理，界面或提示说明实际作用和时长，不能把娱乐行为记成已经认定的违规处罚。

管理员按群启停娱乐能力，配置骰子面数、自助禁言概率、时长上限、冷却与保底，未配置不启用。命令仅作用于主动发起者，不记录为违规。自助禁言到期自动结束，管理员可提前解除，用户不能即时自行解除。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| BE-01：用户使用已开放的骰子命令 | 展示该次结果及适用规则 |
| BE-02：用户主动使用自助禁言 | 结果与对发起者的实际处理一致，不登记为违规处罚 |
| BE-03：某群未开放对应娱乐功能 | 明确说明不可用，不执行对应动作 |

## 配置与后续事项

业务规则已确认，具体数值由后台配置。命令名称和结果排版在界面实现时确定，不改变主动使用与解除规则。
