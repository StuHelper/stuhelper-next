# 机器人娱乐功能

## 范围

娱乐功能作为独立菜单保留，包括掷骰子、自助禁言等旧机器人娱乐命令。与群聊管理中的违规处罚分开，也不放入信息查询菜单；具体玩法参数仍待确认。

## 用户与管理员体验

用户主动调用已经开放的娱乐命令，能够知道命令用途和实际结果。掷骰子返回该次结果；自助禁言按选定玩法对发起者处理，界面或提示说明实际作用和时长，不能把娱乐行为记成已经认定的违规处罚。

管理员可管理娱乐能力是否开放及相应规则。玩法中的面数、概率、时长、上限、冷却、保底与允许使用的群需要明确配置，不直接继承旧机器人默认值。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| BE-01：用户使用已开放的骰子命令 | 展示该次结果及适用规则 |
| BE-02：用户主动使用自助禁言 | 结果与对发起者的实际处理一致，不登记为违规处罚 |
| BE-03：某群未开放对应娱乐功能 | 明确说明不可用，不执行对应动作 |

## 待确认事项

首期具体命令、允许的场景、概率与时长规则、冷却和保底方式、主动解除自助禁言的规则及结果展示形式尚待确认。
