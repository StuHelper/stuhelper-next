# 存储放置与恢复

## 范围与状态

**已启动基础实现，尚未完成全量验收。** 本文记录全系统文件在多实例、多 adapter 存储中的行为与剩余验收。通用文件和存储职责分开，课程资料是使用方，贡献和激励是扩展。实现范围见[实施准备](../development/storage-module.md)。

当前只要求抵御账号失效、撤权、容量不足、误删和文件损坏，不考虑 BHpan 整体服务故障。不同账号可属于同一 BHpan 服务，不以跨供应商放置作为准入、发布或验收条件。

## 分类与准入

业务访问规则、文件保护要求、实例准入授权和交付策略分别记录。平台与用户实例均按允许分类、学校或组织范围、保护条件及有效期判断准入。普通贡献默认仅承载可公开分发内容，受限用途须由获授权管理员另行批准并满足保护要求。

分类采用[可配置保护策略](../design/storage-architecture.md)。候选方案要求受限文件写入用户实例前采用应用层加密、独立密钥管理并验证恢复。仅标记可信或存在账号授权不足以准入；缺少合格目标时拒绝新写，不降低分类或扩展授权范围。

受限文件的应用层加密明确延期；要求密文的用户实例用途暂不开放。过渡期仅使用有明文保管授权的平台私有实例，延期不自动授予普通贡献者明文保管权。后续加密场景不列为未启用用途的基础发布条件。

未分类、未审和分类冲突的文件先进入获准隔离实例。账号协议与来源不自动授予密级；允许学校 A 的内部文件不包含其他学校。加密后的表示形式保留原保护要求，不能因密文可读性降低而任意放置。

新业务引用、密级调整和策略迁移检查全部有效引用约束。提高保护要求时先停止不合规交付；降低保护要求须重新审核。无有效引用时才进入按保留规则清理的流程，某个业务释放引用不删除其他业务仍需的文件。

## 实例、能力与容量

平台按供应商稳定账号标识识别实例故障域，重复账号或同账号不同目录不得增加独立副本数。同一贡献者的多个账号不能满足不同贡献者约束。实例归属变化、凭据轮换和账号重新授权使用修订号并重新验证。

adapter 能力按验证结果开放。配额、指定版本读取、直链、分片上传、归档和远端复制可以分别不可用；业务不因其中一个扩展不可用而绕过授权或校验。不同 adapter 可承担同一对象的不同副本，发布和读取只计入满足该对象策略的副本。

新写要求实例健康、授权有效、容量样本有效、期限充足且不处于暂停或排空状态。并发请求在持久化账本中原子预占物理容量。供应商容量与贡献额度共同约束预算，保留个人空间、安全余量以及未确认写入占用。

配额下降、采样过期或凭据失效后停止新写并显示具体状态。读取、修复来源、删除和排空按各自能力判断，不把停止新写等同于整账号所有操作都不可用。

## 上传、发布与降级

上传先落在获准受控隔离区，未明确分类时按受限要求保护。核对实际大小、SHA-256、类型和内容校验结果；请求成功或供应商 ETag 不等于内容验证成功。必要的业务审核和分类通过后，再安排符合目标策略的副本。

首期目标确认为三份完整副本，包含首份。发布门槛是新版本首次提供存储就绪结果所需的独立、完整、合规且校验通过的副本数，确认为两份；业务仍需通过当前审核和发布检查。参数由后台配置。

未达门槛时显示“等待冗余完成”，不显示发布成功；达到门槛但未达目标时明确显示欠副本并安排补齐。首次上传、本次发布与后台修复分别展示状态，不能把缺少第三份的对象标为已达到目标。

已发布版本丢失部分副本后可从剩余合规副本交付，不改变业务访问权。全部副本不可用时返回稳定状态，不把空文件或部分内容作为成功结果。无法找到可信来源时进入恢复处置，所属业务独立处理购买及其他交付义务。

## 读取与目录

下载签发和网关每次校验业务访问权、版本状态及副本合规性。直链只有在供应商指定版本、防替换与五分钟失效约束已验证时开放，否则使用受控网关。受限资料不返回贡献者分享链接或供应商明文地址。

目录下载固定当前有权访问的版本集合，不列出无权资料的缺项。所有下载包合计必须与该集合完全一致且每项恰好一次。原生归档能力未通过验证时关闭该路径；不能将整个物理目录代替授权选集。

多包下载支持逐包刷新和重试。请求计划与实际领取下载包时都检查授权；权限变化使旧包不可继续交付时重新生成计划，已传出的内容按现有文件签名规则处理。临时包按数据保留规则到期删除。

## 修复、退出与删除

多实例任务领取、容量预占与最终提交通过持久化事务协调。任务携带对象版本、分类、策略、实例准入及凭据修订和执行代次；过期租约、已撤权凭据或旧代次不能提交健康结果。重复事件和客户端重试沿用同一操作身份。

每个远端阶段前后重查分类和授权。提高密级或撤销实例准入后不推进旧任务，存量副本安排合规迁移；已送达供应商的结果按残留处理。所属业务核对当前审核与文件服务就绪结果的版本及修订，不能依靠迟到事件重新开放内容。

远端调用超时进入结果待确认，先查询已记录的远端身份再决定重试或补偿。未知写入不能直接释放容量并重建同名副本。暂存对象、回收站对象和无法清理的残留分别登记，不计入健康副本。

修复和退出迁移先复制并核验替代副本，再原子切换当前集合，最后清理旧文件。已删除版本、被取消任务和已撤权账号的迟到结果只进入清理流程。清理仅针对平台明确拥有的远端对象，不影响贡献者的个人文件。

暂停或退出立即停止新放置；正常退出在迁移和清理完成后结束。立即撤权先停止凭据使用并使旧任务失效，继续从其他副本恢复；无法访问原账号时明确显示迁移或远端清理尚未完成。

BHpan 移入回收站、彻底删除和平台确认完成是不同状态。只有凭据失效、网络失败或查询权限不足不能证明文件已删除。清理记录保留到满足[数据保留规则](data-retention.md)，恢复备份后继续执行删除，不能复活已停用版本。

## 观测与配置

贡献扩展通过接口取得核验统计，向用户展示本人额度、用量、期限、授权和退出进度。公开透明度沿用[贡献规格](storage-contribution.md)；欠副本、损坏副本和清理积压供获授权运维查看。存储核心不读取奖励或课程业务表。

副本数、发布门槛、容量采样时限、校验周期、迁移提前量、并发和带宽预算由后台管理。策略更新带修订号，展示受影响对象并生成迁移任务；历史副本必须重新达到新策略，不能仅修改目标数字就标为合规。

新增 adapter 使用同一组端口行为测试，并额外验证供应商特有语义。BHpan 真实账号演练使用隔离根和无敏感测试文件，凭据及短期 URL 不写入仓库、日志或夹具。

当前管理操作包括实例暂停、恢复暂停、排空、撤销、平台额度调整和阻塞任务重试。读取状态、修改实例与重试任务使用独立权限。接口不返回供应商账号、凭据引用、根目录或内容摘要，也不为读取状态访问供应商。

命令携带修订或任务代次与幂等键，并在同一事务记录操作和事件。额度不得低于已用与预占之和。恢复暂停不延长授权，已撤销或到期实例须重新核验。人工重试检查当前分类准入并保留原远端身份，不能绕过未知写入查证。

## 验收场景

以下为完整验收目标。存储核心的已实现子集登记于其 module.json，详见[实施状态](../development/storage-module.md)；跨模块发布、目录、持续贡献及恢复尚未全部完成，不将局部测试计作全部通过。

| 场景 | 预期结果 |
| --- | --- |
| SP-01 | 同一 BHpan 账号通过不同登录方式或目录重复登记时，不增加容量与独立副本数 |
| SP-02 | 同一贡献者拥有多个账号时，不能满足跨贡献者副本约束 |
| SP-03 | 同一 BHpan 服务内的独立账号满足策略时，可完成放置与发布，无跨服务商要求 |
| SP-04 | 未审、未分类或超出实例允许分类、学校或组织范围的写入被拒绝；账号可信标记不能绕过 |
| SP-05 | 用户实例承载受限密文的正向验收延期；基础阶段验证缺少必要加密、恢复或准入条件时拒绝。未来启用后另验合规放置和认证失败不输出明文 |
| SP-06 | 新引用提高保护要求时，先完成合规放置或建立独立版本，不复用不合格副本 |
| SP-07 | 两个 API 实例并发预占同一账号时，总量不超过实际预算；未知写入不提前释放预算 |
| SP-08 | 容量下降、样本过期或即将到期时停止新分配，仍按能力允许读取与排空 |
| SP-09 | 只有上传成功而摘要不符时，副本不健康，资料不能按该副本达到发布门槛 |
| SP-10 | 新版本未达发布门槛时保持等待；达门槛未达目标时开放并明确欠副本 |
| SP-11 | 已发布版本的账号失效、误删或内容损坏时，从其他健康副本读取并修复 |
| SP-12 | 所有副本均不可用或损坏时停止交付，不返回空文件或复制损坏内容 |
| SP-13 | 修复写入完成但提交前 worker 崩溃时，重领任务先核查远端，不重复计数或覆盖有效副本 |
| SP-14 | 旧租约、旧任务代次或撤权前回执晚到时，不能覆盖新状态或提交健康副本 |
| SP-15 | 替代副本未完整校验时不删除原健康副本；全部满足后原子切换 |
| SP-16 | 用户暂停或退出后停止新写；正常迁移完成后才报告退出完成 |
| SP-17 | 用户立即撤权或外部改密时停止使用凭据，迁移与远端清理未完成状态仍可见 |
| SP-18 | 删除只进入 BHpan 回收站或原账号已失联时，不报告物理清理完成 |
| SP-19 | 对象停用或删除后收到迟到修复结果时，只清理残留，不恢复下载入口 |
| SP-20 | 平台和用户提供的两种 adapter 实例按同一准入规则参与读取和修复；ETag 与供应商版本不代替内容摘要 |
| SP-21 | BHpan 直链期限或指定版本语义未经验证时，仅使用受控网关交付 |
| SP-22 | 目录混有无权文件时，下载包精确覆盖授权选集；过期授权不继续交付旧包 |
| SP-23 | 账号重新授权或故障恢复后，先探测、核验内容与容量，再恢复参与放置 |
| SP-24 | 元数据恢复后能定位并验证存量文件，且已删除对象不会重新开放；密钥恢复在加密功能未来启用时另行验收 |
| SP-25 | 公开页面、审计与日志不含账号、凭据、短期 URL、个人目录或敏感内容 |
| SP-26 | 复制或发布期间分类提高、准入撤销、策略变化或审核撤回时，旧任务和就绪事件不能开放内容，残留进入清理 |
| SP-27 | 并发上传相同内容只写入同范围、同保护要求的一组副本；摘要本身不授予读取或免上传资格 |
| SP-28 | 释放或迁移一个逻辑引用保留其他引用；最后一次释放及迁移中取消须完成相关物理清理 |

## 共享内容

共享分组包含服务身份、完整保护要求、长度、SHA-256 与副本策略。新引用先验证实际字节或当前已有来源权限，再取得可读状态。共享内容保持原有目标副本数，容量只按实际物理副本占用。

逻辑引用独立保存业务引用和发布状态。保护变更保留来源并持久化目标分组，目标校验成功后才切换，其他引用不受影响。二十四小时无业务引用的记录限量清理，失败组按上次尝试时间轮转。

访问资格、发布与停用由所属业务决定；课程资料遵循[资料共享](resource-sharing.md)。贡献与透明度遵循[存储贡献](storage-contribution.md)，上传引用遵循[文件与媒体](media.md)，事件、幂等和签名期限遵循[模块通信](module-protocol.md)。
