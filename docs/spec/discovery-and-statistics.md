# 内容发现、排行与评价趋势

## 范围

保留热门课程、热门教师、课程评分趋势和我的投票，补充课程与教师的发现体验。导师评论采用自由文本，不设置评分维度。教师评分来自其所授课程的课程评价，教师没有独立评价入口。

## 用户体验

| 入口 | 用户能够看到和操作的内容 |
| --- | --- |
| 热门课程 | 发现当前榜单中的课程，进入课程详情、评价与资料 |
| 热门教师 | 发现教师，进入其开课列表和评价 |
| 课程评分趋势 | 按所选统计范围理解课程评价的变化，查看样本量和时间范围 |
| 我的投票 | 查看本人对评课的点赞或点踩，回到对应内容，按评课规则切换或取消 |

评分趋势继续使用已确认的五级文字和表情语义，不因加入统计图就显示精确评分数字。评价数量和统计时间可以明确展示；没有样本、样本较少和评价较低需要区分。

发现入口遵循内容自身的阅读条件，不能通过排行、搜索摘要或统计详情取得本来无权查看的正文。热门课程与教师按浏览、评价、收藏和互动等指标计算热度，权重、时间窗口和最低样本量由后台配置。热度与课程评分派生的教师评分分别展示，不从导师文字评论生成评分。

## 评分统计与课程对比

课程与教师五维评分统计由 reviews 的 GET /api/v1/reviews/statistics 提供。课程对比由客户端分别读取 2—5 门课程的统计并组合展示，沿用 reviews 的当前内容准入、学校范围、五级展示等级与样本量规则。

## search 模块边界

search 负责可重建索引、关键词搜索、热门课程与教师，以及我的投票查询。业务内容由原模块维护，评分统计由 reviews 提供。索引使用来源对象 ID、修订号、公开检索字段及可见状态。事件重复和乱序按[模块通信规则](module-protocol.md)处理，正常索引更新目标为 60 秒内。

搜索和榜单返回前检查当前可见性及访问范围。删除、撤回、下架与权限变化立即影响查询结果，过期索引仅作为候选集合。索引不可用时显示搜索暂不可用，已完成的业务写入继续有效。恢复时按来源接口和修订号重建索引。

我的投票通过 reviews 的本人投票接口取得记录，再通过内容接口检查当前可读性。catalog、reviews、resources 与 community 为可选来源，缺少来源时只影响对应内容。search 不保存独立评分统计。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| DS-01：从热门课程或教师进入详情 | 对应对象和上下文一致 |
| DS-02：切换趋势统计范围 | 时间范围与样本量明确，不展示精确评分数字 |
| DS-03：没有评价样本 | 显示无评价，不显示为最低评分 |
| DS-04：用户打开我的投票 | 显示本人的有效选择，支持回到原内容 |
| DS-HEAT：热度配置 | 权重、窗口与最低样本量生效，课程与教师热门结果使用当前可见来源 |
| DS-TRANSACTION：投影写入失败 | inbox 与投影全部回滚，不确认事件 |
| DS-PROJECTION：重复、乱序与重建 | 重放去重、旧修订忽略，重建失败保留原投影，运行身份不得越界访问 |

## 配置与后续事项

课程五维趋势显示样本量，未达到配置的最低样本时显示“暂无足够数据”。统计只纳入当前可见的有效评价。教师评分按评价规格先算课程均分、再对课程等权汇总，具体图形与同分稳定排序在实现设计中确定。
