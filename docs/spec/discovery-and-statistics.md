# 内容发现、排行与评价趋势

## 范围

保留热门课程、热门教师、课程评分趋势和我的投票，补充课程与教师的发现体验。导师评论采用自由文本，不设置评分维度。教师评分来自其所授课程的课程评价，教师没有独立评价入口。

## 用户体验

| 入口 | 用户能够看到和操作的内容 |
| --- | --- |
| 热门课程 | 发现当前榜单中的课程，进入课程详情、评价与资料 |
| 热门教师 | 发现教师，进入其开课列表和评价 |
| 课程评分趋势 | 按所选统计范围理解课程评价的变化，查看样本量和时间范围 |
| 我的投票 | 查看本人对评课的点赞或点踩，回到对应内容，按评课规则切换或取消 |

评分趋势继续使用已确认的五级文字和表情语义，不因加入统计图就显示精确评分数字。评价数量和统计时间可以明确展示；没有样本、样本较少和评价较低需要区分。

发现入口遵循内容自身的阅读条件，不能通过排行、搜索摘要或统计详情取得本来无权查看的正文。热门课程与教师按浏览、评价、收藏和互动等指标计算热度，权重、时间窗口和最低样本量由后台配置。热度与课程评分派生的教师评分分别展示，不从导师文字评论生成评分。

## 评分统计与课程对比

课程与教师五维评分统计由 reviews 的 GET /api/v1/reviews/statistics 提供。课程对比由客户端分别读取 2—5 门课程的统计并组合展示，沿用 reviews 的当前内容准入、学校范围、五级展示等级与样本量规则。

## search 模块边界

search 负责可重建索引、关键词搜索、热门课程与教师，以及我的投票查询。业务内容由原模块维护，评分统计由 reviews 提供。索引使用来源对象 ID、修订号、公开检索字段及可见状态。事件重复和乱序按[模块通信规则](module-protocol.md)处理，正常索引更新目标为 60 秒内。

搜索和榜单返回前检查当前可见性及访问范围。删除、撤回、下架与权限变化立即影响查询结果，过期索引仅作为候选集合。索引不可用时显示搜索暂不可用，已完成的业务写入继续有效。恢复时按来源接口和修订号重建索引。

我的投票通过 reviews 的本人投票接口取得记录，再通过内容接口检查当前可读性。catalog、reviews、resources、favorites 与 community 为可选来源，缺少来源时只影响对应内容。search 不保存独立评分统计。

## 热度指标与来源

浏览、评价、收藏和互动四项指标由拥有事实的模块分别统计。search 按来源保存日快照，再按目标与统计窗口汇总，使用配置权重计算热度。最低样本量取四项有效计数之和，不受权重影响。

| 来源 | 指标 | 统计规则 |
| --- | --- | --- |
| catalog | 浏览 views | 已登录账号成功读取课程或教师详情时，同一账号、规范对象、UTC 日只计一次；列表和内部事实读取不计数 |
| reviews | 评价 reviews、互动 interactions | 按本模块有效性规则统计当前可见的课程评价、有效投票与回复 |
| favorites | 收藏 favorites | 当日新增减当日取消，对外下限为 0；内部保留有符号净额，跨日取消计入取消日 |

收藏跨日取消不重写原新增日。例如周一新增一条、周二取消，周一为 1、周二为 0。周二随后新增一条仍为 0，再新增一条才为 1。重复新增与收藏移动不重复计数。

catalog 浏览统计尽力写入，统计失败不阻断已获准的详情读取，故障期间可能少计。去重、计数、修订和活动 outbox 在独立事务中一起成功或回滚。

活动使用 discovery.activity.v1，按来源与活动 ID 分别保存，修订独立递增。新修订完整替换原快照，重复事件不累加，零值显式保存。来源只能发送自己拥有的指标，课程活动不自动复制到教师。

来源明确缺失或未启用时贡献计 0；已启用来源的超时、查询失败或无效响应返回暂不可用。查询仍复核当前活动修订、可见性和目标权限，修订不匹配的快照暂停计入。重建时任一已启用来源失败，全部投影回滚。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| DS-01：从热门课程或教师进入详情 | 对应对象和上下文一致 |
| DS-02：切换趋势统计范围 | 时间范围与样本量明确，不展示精确评分数字 |
| DS-03：没有评价样本 | 显示无评价，不显示为最低评分 |
| DS-04：用户打开我的投票 | 显示本人的有效选择，支持回到原内容 |
| DS-05：热度配置 | 各模块只统计自身指标，浏览按账号、对象和 UTC 日去重，收藏跨日取消计入取消日；权重、窗口与最低样本量生效 |
| DS-06：投影写入失败 | inbox 与投影全部回滚，不确认事件；重复活动不累加，已启用来源失败不伪报为零 |
| DS-07：重复、乱序与重建 | 重放去重、旧修订忽略，重建失败保留原投影，运行身份不得越界访问 |

## 配置与后续事项

课程五维趋势显示样本量，未达到配置的最低样本时显示“暂无足够数据”。统计只纳入当前可见的有效评价。教师评分按评价规格先算课程均分、再对课程等权汇总，具体图形与同分稳定排序在实现设计中确定。
