# 全站信息关联查询

## 范围与入口

“信息查询”是独立业务菜单，与“群聊管理”和“娱乐功能”分开。管理后台提供完整的跨全站关联查询，机器人查询能力另行按权限配置。此功能已确认纳入重构，用于管理员查阅关联业务记录。学生认证时的信息比对由[认证流程](student-verification.md)另行处理。

## 查询线索与关联视图

管理员可按学号、姓名、QQ 等线索查找记录，进入关联对象的业务视图。学号保留学校上下文；姓名重名时展示候选对象，不直接把同名记录合并。QQ 关联到的平台账号、学生身份及其他记录应能让操作者理解关联来源。

| 数据域 | 已确认纳入查询的业务范围 |
| --- | --- |
| 身份与认证 | 学籍、学校、学习经历、学生认证、实名状态、账号与 QQ 等关联资料 |
| 内容 | 对应用户的课程/教师评价、资料及相关业务记录 |
| 群聊 | 入群认证、成员资格处理和群管理记录 |
| 会员与权益 | 会员、特权群体及单独授予的业务访问权 |
| 积分与 Ivory | 账户情况及相关获取、消费、到期等记录 |
| 消费与退款 | 资料解锁、充值、消费及退款申请和结果 |

查询覆盖上述业务域。每个视图展示哪些字段、是否脱敏、能否查看原始材料和导出数据，仍需逐项确认。

## 使用者与权限范围

平台管理员可查询全站业务范围。其他管理员按其负责的学校、群及业务模块授权查询；授权到某个群，不自动取得该群成员全部财务记录，授权到内容管理也不自动取得认证材料。

同一用户的多个业务域可以在后台统一入口展示，但每一部分仍按操作者的有效范围决定是否可见。缺少某域查询权限时，不能用其他已获授权的关联线索绕过该限制。

查询与修改是不同能力。能查看某笔退款、积分或认证记录，不自动获得付款、发放积分、修改认证或删除内容的操作权；需要执行操作时进入该业务对应的管理流程。

## 机器人入口

机器人侧是否开放某类查询、允许哪些操作者、在哪些私聊或群场景提供结果，以及返回哪些字段，另行配置和确认。管理后台可查询全站，不代表机器人可在任意群公开同样的完整结果。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| IQ-01：平台管理员从 QQ 查到已关联用户 | 可按业务域查看该用户相关记录及关联关系 |
| IQ-02：学校或群管理员查询对象 | 只展示其获准学校、群及业务模块范围 |
| IQ-03：查询姓名出现多个不同对象 | 展示可区分候选，不把重名者的数据拼成一人 |
| IQ-04：操作者可查内容但无钱包查询权 | 内容可见，积分/Ivory 与退款记录不能借关联查询取得 |
| IQ-05：机器人没有该类查询授权 | 不因后台存在相同能力而自动向群或私聊返回结果 |

## 待确认事项

具体查询字段、证件与材料的展示范围、财务明细与收款信息的明文规则、历史绑定变更的展示、机器人命令及交付场景、导出能力和批量查询范围尚待确认。技术设计在这些业务选择确定后继续完善。
