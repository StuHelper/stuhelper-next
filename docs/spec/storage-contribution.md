# 存储贡献

## 范围

用户自愿贡献支持的网盘或存储容量，帮助平台保存可分发的学习资料，并能查看与管理本人贡献。该业务及贡献榜已确认纳入重构，不直接继承旧存储系统的副本、编码、修复和调度实现。

## 用户流程

用户选择支持的存储方式，完成所需授权，设置贡献容量、个人保留空间和贡献期限。贡献面板展示贡献量、实际占用、期限和当前是否可用。

用户可以续期、在授权失效后重新授权、暂停贡献或申请退出。暂停接收新资料与已经存放资料的处理需要区分；退出过程应能向用户说明正在处理什么，不能只将界面标为退出而仍无说明地继续使用容量。

## 社区体验

贡献榜展示参与贡献的用户及贡献情况，具体上榜选择、排序与公开字段尚待确认。

增加存储贡献透明度页面，展示平台整体贡献容量、使用情况、可用容量、服务状态和更新时间。统计应区分用户申报的容量与平台实际可用的容量。具体指标和公开字段在页面设计时确认。

持续贡献存储容量可以获得积分；奖励依据、额度和周期由[积分规则](wallet-and-points.md)中的相关配置确定。贡献榜与积分奖励不是同一统计，不能默认按宣称容量无限发放积分。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| ST-01：用户设置贡献量和保留空间 | 可查看所设条件及实际占用 |
| ST-02：贡献即将到期或授权失效 | 显示状态，提供续期或重新授权入口 |
| ST-03：用户暂停或申请退出 | 显示进度与结果，能够理解既有资料如何处理 |
| ST-04：平台展示贡献容量 | 区分申报容量与实际可用情况 |
| ST-05：用户查看透明度页面 | 能看到统计范围、整体状态和更新时间 |

## 待确认事项

支持的服务商、最低容量与期限、退出完成时限、已有文件迁移安排、贡献榜公开方式、奖励依据及受限资料能否使用贡献存储均待确认。资料公开或受限的访问规则由[资料规格](resource-sharing.md)定义，不能由存储来源自行改变。
