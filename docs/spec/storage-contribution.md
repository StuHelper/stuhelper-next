# 存储贡献

## 范围

用户自愿贡献已接入后端的存储容量，供 StuHelper 各业务按保护策略使用，并能查看与管理本人贡献。贡献生命周期与通用存储、具体业务及激励规则分别维护；贡献生命周期、后端可选装配及 Web/Admin 管理页面已实现，真实贡献入口保持关闭。

首期实际候选为 BHpan，贡献模型同样适用于通过验证的 S3、COS 等后端。协议、平台或用户来源、允许承载分类三个维度独立。当前不考虑整个 BHpan 服务故障，不要求跨服务商副本，见[放置与恢复](storage-placement.md)。

## 用户流程

只开放已经实际接入的服务商。贡献容量、个人保留空间、最短期限与退出处理期限由后台配置。用户选择支持的存储方式，完成所需授权，设置贡献容量、个人保留空间和贡献期限。贡献面板展示贡献量、实际占用、期限和当前是否可用。

用户可以续期、在授权失效后重新授权、暂停贡献或申请退出。暂停或退出后停止接收新文件，平台迁走既有文件后才确认退出完成。外部授权失效或容量不足时明确告知，不继续计入实际可用容量。

请求先保存为 pending，desired_state 表示请求目标，applied_revision 表示存储端已确认修订。用户同意期限由存储核心检查，后台未运行时也会停止新写入。退出仅在副本记录、占用和预留全部归零后完成，撤权但未清理时保留明确原因。

首期 API 绑定预先验证的暂停空闲实例，不接收供应商密码或会话。条款版本、摘要、期限与容量由配置给出。公开统计使用有效观测计算可用量，过期或授权失效的容量不计入可用量。接口及当前限制见[实施状态](../development/storage-module.md)。

本人候选列表由已验证身份确定，只包含预先授权、暂停、无占用且未绑定的实例。查询不登录或探测供应商。面板明确区分请求目标和处理状态；网络结果不明时保留原请求与幂等键，权限撤销后清空私有数据。

管理员使用独立读取和重试权限，查看脱敏状态及迁移进度。重试只恢复用户原请求，不能扩大额度、期限或同意范围。后台维护身份不能获得管理权限。

## 首次接入与重新授权

账号托管由通用存储服务负责。用户明确授权用途与截止时间，首次接入后登记暂停实例，再单独选择贡献容量。BHpan 统一认证模式需说明学校密码仅用于 BHpan 重登；密码通过同源接口提交并加密保存。

更新使用独立客户端验证原账号和专用根，成功后按候选修订切换凭据。错误密码保留旧凭据与会话；撤销会阻止此前开始、随后返回的核验结果生效。原专用根、副本、贡献条件和密级准入保持不变。

浏览器提交后清空凭据，响应不明只保留原申请标识。管理员仅能查看脱敏状态并恢复原申请，不能读取密码、替用户同意或扩大授权。申请状态与审计归存储模块，奖励和课程业务不参与凭据管理。

## 社区体验

贡献榜、奖励计算及贡献到账务的接入明确延期，不作为首期贡献功能的依赖。未来贡献榜只展示主动选择上榜者的昵称、头像和贡献统计，不公开存储账号。

增加存储贡献透明度页面，展示平台整体贡献容量、使用情况、可用容量、服务状态和更新时间。统计应区分用户申报的容量与平台实际可用的容量。公开指标为申报容量、实际可用容量、使用量、服务状态和更新时间。

当前贡献不产生积分。未来奖励由私有账务按独立规则消费获授权的核验统计，不按宣称容量直接发奖。贡献统计及生命周期不依赖奖励模块，也不因奖励关闭而停止账号接入或容量使用。

普通贡献准入默认仅承载可公开分发文件。获授权管理员可为具体实例批准受限分类、学校或组织范围和有效期；实现后仍须满足对应加密及恢复要求。账号拥有者不能自行提升密级，平台自有实例也不能跳过准入规则。

批准保存密文不授予明文阅读权，用户实例承载受限文件的默认候选是应用层加密及独立密钥管理。项目负责人已明确暂不实现受限文件加密，要求密文的用途继续关闭，不自动改为明文。未分类和待审文件进入获准隔离区，不能借普通贡献准入提前分发。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| ST-01：用户设置贡献量和保留空间 | 可查看所设条件及实际占用 |
| ST-02：贡献即将到期或授权失效 | 显示状态，提供续期或重新授权入口 |
| ST-03：用户暂停或申请退出 | 显示进度与结果，能够理解既有资料如何处理 |
| ST-04：平台展示贡献容量 | 区分申报容量与实际可用情况 |
| ST-05：用户查看透明度页面 | 能看到统计范围、整体状态和更新时间 |
| ST-06：接入另一种已验证 adapter | 沿用贡献生命周期和存储准入，不修改课程资料业务 |
| ST-07：关闭奖励或贡献扩展 | 关闭奖励仍可贡献，关闭贡献仍可使用平台实例与通用文件能力 |
| ST-08：浏览器遇到未知结果或权限撤销 | 重试原请求保持幂等键，权限撤销清空私有内容 |
| ST-09：管理员处理阻塞贡献 | 读取和重试分别授权，原用户条件保持不变 |
| ST-10：用户接入或更新存储账号 | 明确同意，提交后清空凭据，未知结果核对原申请，原绑定与贡献条件保持 |
| ST-11：管理员恢复托管申请 | 只恢复原同意与修订，不接收凭据，未登录或撤权立即清空私有内容 |

## 配置与后续事项

同意、条件管理、暂停、续期、退出、撤权和汇总 API 已实现，七组模块场景及后端隔离联调通过。贡献面板、存储托管入口及管理员恢复页面已实现。上榜、奖励及账务接入延期；当前剩余入口工作为实际应用登录和真实账号接入验收。

服务商按实际接入能力开放，容量与期限由后台配置；文件访问权由所属业务决定，不能由实例来源或贡献奖励改变。课程资料的具体规则见[资料规格](resource-sharing.md)。

首期使用获准托管凭据重登及有效会话复用，无密码续期仅为后续可选优化。实际入口仍需验证当前授权、凭据变更、撤权和清理，不能以底层登录成功代替用户流程验收。三副本目标、两份发布门槛及已有证据见[实施准备](../development/storage-module.md)。
