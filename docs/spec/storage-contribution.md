# 存储贡献

## 范围

用户自愿贡献支持的网盘或存储容量，帮助平台保存可分发的学习资料，并能查看与管理本人贡献。该业务及贡献榜已确认纳入重构，不直接继承旧存储系统的副本、编码、修复和调度实现。

## 用户流程

只开放已经实际接入的服务商。贡献容量、个人保留空间、最短期限与退出处理期限由后台配置。用户选择支持的存储方式，完成所需授权，设置贡献容量、个人保留空间和贡献期限。贡献面板展示贡献量、实际占用、期限和当前是否可用。

用户可以续期、在授权失效后重新授权、暂停贡献或申请退出。暂停或退出后停止接收新文件，平台迁走既有文件后才确认退出完成。外部授权失效或容量不足时明确告知，不继续计入实际可用容量。

## 社区体验

贡献者主动选择上榜，只展示昵称、头像和贡献统计，不公开存储账号。

增加存储贡献透明度页面，展示平台整体贡献容量、使用情况、可用容量、服务状态和更新时间。统计应区分用户申报的容量与平台实际可用的容量。公开指标为申报容量、实际可用容量、使用量、服务状态和更新时间。

持续贡献存储容量可以获得积分，公开模块向账务服务提供获授权的贡献统计，奖励规则由私有账务规格维护。贡献榜与积分奖励不是同一统计，不能默认按宣称容量无限发放积分。

首期贡献存储只保存可公开分发的资料。受限资料使用平台管理的存储，贡献存储支持受限资料的方案已明确延期。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| ST-01：用户设置贡献量和保留空间 | 可查看所设条件及实际占用 |
| ST-02：贡献即将到期或授权失效 | 显示状态，提供续期或重新授权入口 |
| ST-03：用户暂停或申请退出 | 显示进度与结果，能够理解既有资料如何处理 |
| ST-04：平台展示贡献容量 | 区分申报容量与实际可用情况 |
| ST-05：用户查看透明度页面 | 能看到统计范围、整体状态和更新时间 |

## 配置与后续事项

上述业务规则已确认。服务商按实际接入能力开放，容量与期限参数由后台配置。资料公开或受限的访问规则由[资料规格](resource-sharing.md)定义，不能由存储来源自行改变。
