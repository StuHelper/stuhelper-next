# 内容运营与审核

## 范围

后台内容运营已确认纳入重构，包括内容审核、举报处理、隐藏与恢复、作者修改/删除申请、管理员主动编辑和处理反馈。审核与复核岗位按[管理角色配置](admin-operations.md)授权。

## moderation 模块边界

moderation 拥有审核任务、举报、复核、处置决定与授权记录。内容模块保存正文及实际可见状态，并按已确认的决定执行状态变化。请求包含对象、内容修订号、动作与幂等标识；处理过期版本时返回冲突并要求复核当前内容。

审核决定与 outbox 在同一事务保存，内容模块按决定 ID 幂等执行。任务完成状态包含决定和实际执行结果，未执行成功的步骤继续重试或进入人工处理。模块通信与保留期限使用公共规格。

## 工作台与处理流程

审核顺序按内容类型配置，初始规则如下：

| 内容 | 初始审核方式 |
| --- | --- |
| 普通课程评价、导师评价和回复 | 默认直接发布，根据规则决定是否拦截、发布后标记复核或转为先审核 |
| 资料首次上传 | 审核通过后发布 |
| 资料新文件版本 | 审核通过后发布新版本，审核期间沿用原可用版本 |

管理员可以修改不同内容类型的审核方式，用户操作资格通过[动作资格配置](action-eligibility.md)维护。用户能区分已发布、等待审核和未获通过，并看到相应处理结果。

管理员在自己的管理范围内查看待处理内容、举报及作者申请，按内容类型、状态、学校和时间筛选，进入详情查看内容及对应申请。一个内容的多项处理记录可以集中查看，避免管理员不知道已有处理结果。

| 事项 | 已确认业务能力 |
| --- | --- |
| 内容审核 | 查看待审内容，给出处理决定并说明结果 |
| 举报 | 查看举报对象和原因，判断是否成立并处理，向举报者反馈结果 |
| 内容隐藏与恢复 | 管理员隐藏不适宜展示的内容，符合恢复条件时恢复展示 |
| 评价修改申请 | 查看作者提出的修改，决定是否采用并向作者反馈 |
| 管理员主动编辑 | 在管理范围内主动修改内容，保留修改前后内容和管理员修改说明 |
| 评价删除申请 | 查看申请与内容，决定是否删除并向作者反馈 |
| 删除恢复 | 管理员可以恢复已删除内容，向相关用户反馈结果 |
| 匿名与署名切换 | 管理员统一切换某用户在一条讨论中的身份及全部回复，不提供用户侧切换申请入口 |
| 资料下架申请 | 查看资料、申请原因及已有购买等相关情况，按资料规则处理 |

课程评价、导师评论和回复的五分钟删除与撤回重编、24 小时草稿期限见[评价规格](academic-content.md)。窗口之外的修改与删除申请由管理员处理。作者按窗口直接删除和撤回超时清理均为永久删除，管理界面的恢复功能只适用于仍保留数据的管理处置。资料的下架处理与作品授权存续分别判断，见[资料规格](resource-sharing.md)。

作者可以对内容处置提交复核申请，说明异议并查看处理结果。管理员主动修改内容不改变作者归属，处理记录应能区分作者原文、作者提交的更正与管理员修改。

作者可以查看针对本人内容的决定并申请复核。其他用户提交的举报理由、证据及修改草案不向内容作者公开，举报者仍可查看自己提交的信息。

## 状态与反馈

用户能够查看本人申请处于等待处理、已处理或未获通过等状态，查看管理员反馈。处理通知进入[通知中心](notifications.md)，并可返回对应内容或申请。

隐藏、恢复、删除和资料下架是不同业务结果。后台应说明将发生的变化，不能把隐藏内容表述成永久删除，也不能在操作尚未完成时显示处理成功。

## 规则、批量与认定

违规分类与敏感词规则由后台配置，审核和复核分别授权。处理前展示理由与影响，批量先预览对象，处理后逐项显示结果。复核由另一名具有复核权限的管理员处理，原决定人不能处理对应复核。

有效评价以正常公开且满足已配置条件为准。优质内容由有权限的管理员认定，撤销认定时说明原因。奖励是否发放与追回由私有账务模块依据相应业务结果处理。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| CM-01：作者申请修改已发布评价 | 原内容不因申请提交自动改变，管理员可查看并处理 |
| CM-02：管理员处理举报 | 能查看对象和理由，决定与反馈关联到原举报 |
| CM-03：内容被隐藏后符合恢复条件 | 管理员可恢复，并向相关用户反馈真实结果 |
| CM-04：作者申请下架已被购买的资料 | 能查看相关购买情况，按资料交付与退款规则处理 |
| CM-05：管理员超出本人管理范围进入内容 | 不能因为拥有某个后台角色就处理范围外内容 |
| CM-06：普通评价未命中拦截或待审规则 | 按默认设置直接发布 |
| CM-07：评价命中待审规则 | 显示等待审核，通过后再发布 |
| CM-08：上传资料或提交新文件版本 | 审核通过后发布；新版本待审期间原可用版本保持可用 |
| CM-09：管理员主动修改内容 | 保存修改说明，能区分修改前后内容与原作者 |
| CM-10：作者对处置提出异议 | 可申请复核并查看结果 |
| CM-11：管理员恢复已删除内容 | 原内容按恢复结果重新展示，保留处理记录 |
| CM-12：批量处置多个审核任务 | 先预览，最多 20 项，逐项显示保存或拒绝结果，未知结果可按原请求重试 |
| CM-13：作者查看其他用户举报的处置 | 展示决定和复核入口，隐藏举报者的私密证据 |
| CM-14：认定或撤销优质评价 | 检查权限及当前内容修订，保留理由、历史和审计 |

## 配置与后续事项

业务规则已确认。具体违规分类、敏感词与岗位组合由后台配置，技术实现按当前模块边界设计。
