# 通知中心

## 范围

保留统一站内通知，向用户解释与本人有关的业务结果。消息队列、连接协议和移动推送服务商在后续技术设计中确定。

## 已确认的通知与操作

| 来源 | 通知内容 |
| --- | --- |
| 内容互动 | 本人内容收到回复、点赞等互动 |
| 内容管理 | 内容处理结果、资料下架申请处理结果 |
| 举报 | 本人举报的处理结果 |
| 认证 | 学生认证或实名核验结果，学生认证撤销、删除申请处理结果 |
| 系统 | 与用户有关的系统通知 |

用户可查看通知列表与未读数，将单条通知标记已读，或将全部通知标记已读。点击通知可以进入相关内容、申请或结果页。通知对应内容已无法访问时，说明当前状态，不能只展示无法解释的空白页。

QQ 群内提醒属于[群服务](qq-group-services.md)的业务流程；是否额外同步到站内、邮件或系统推送，需另行确认。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| NT-01：用户收到回复通知 | 列表展示通知，点击进入对应内容 |
| NT-02：用户标记一条或全部已读 | 对应未读状态和未读数更新 |
| NT-03：申请已被管理员处理 | 用户能看到结果并进入相关申请 |
| NT-04：通知关联内容已下架 | 告知内容当前不可用，不误报加载成功但无内容 |

## 待确认事项

各类通知默认开关、聚合方式、保留期限、免打扰和跨端推送渠道尚未确定，不从旧实现直接继承。
