# 国际化与本地化

## 语言清单

应用默认中文，初始支持 `zh-CN`、`en-US`、`fr-FR`、`ru-RU`、`ja-JP`、`ko-KR`、`es-ES` 和 `ar-EG`。语言名称、默认语言、默认时区及文字方向以 `architecture/locales.json` 为准，客户端保存相同配置。新增语言时补齐消息、组件语言适配、复数规则与浏览器场景。

语言选择顺序为明确的页面语言参数、本人已保存偏好、默认中文。页面更新 `lang` 和 `dir`。阿拉伯文使用 RTL，布局边距、侧栏、菜单和组件方向随语言调整。用户创作内容、课程名称、品牌名和代码标识保留其本来语言。

## 消息与复数

应用文案使用翻译键，包含可访问名称、标题、提示、错误、校验、菜单和空状态。八种语言的键集合完整且占位符一致。服务端返回稳定错误码和结构化参数，客户端选择语言进行展示。

使用 Vue I18n 的消息接口与 ICU/CLDR 数据。基数复数按 `zero / one / two / few / many / other` 的有效类别顺序定义，俄文和阿拉伯文分别覆盖其全部类别。序数通过 `Intl.PluralRules` 的 ordinal 规则选择。复数消息包含各分支所需参数，语句整体翻译。

## 时间、数字与金额

公共格式化接口提供数字、百分比、ISO 货币、日期、日期时间、日期范围、日历日期、相对时间、列表与语言排序。数字、货币和日期使用 `Intl`，界面组件同步加载 Ant Design、Day.js 和表格的语言包。

时间点在接口和存储中使用带偏移的 ISO 8601/UTC 表达。界面语言、用户时区与币种分别传递，默认时区为 Asia/Shanghai。日历日期使用 `YYYY-MM-DD`，按日历日期显示；时间点按用户时区显示。日期展示默认公历，格式化选项支持明确选择其他日历。

金额计算和账户存储使用业务定义的精确值。显示金额可以使用十进制字符串，保留超出 JavaScript 安全整数范围的精度。货币展示遵循所选币种的小数位，JPY、CNY、KWD 等分别处理。Ivory 与其他站内单位按数字和单位展示。语言切换保持币种、金额和业务含义不变。

## 检查范围

每个前端的 `check:i18n` 验证八语言键、空消息、占位符和复数类别，并检查已使用的消息键。ESLint 检查界面硬编码文本与消息语法，JSON 检查重复键。格式化测试覆盖复数、精确金额、货币位数、时区跨日和日历日期。

浏览器联调覆盖八语言的桌面和移动端、网络错误恢复、语言切换、默认中文、RTL 和视口宽度。出现缺失键或语言回退警告时检查失败。

| 场景 | 预期结果 |
| --- | --- |
| I18N-01 | 任意语言缺少键、消息为空或参数被改名时，检查失败 |
| I18N-02 | 阿拉伯文按 0、1、2、3、11、100 使用六类复数 |
| I18N-03 | 俄文按数量选择单数、少数、多数与其他形式 |
| I18N-04 | 同一 UTC 时间点切换时区时按当地日期显示，日历日期保持当天 |
| I18N-05 | JPY 与 KWD 分别采用对应货币位数，大额字符串金额保持精度 |
| I18N-06 | 阿拉伯文切换后页面与组件使用 RTL，中文切换后恢复 LTR |
