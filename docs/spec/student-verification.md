# 学生认证的公共对接说明

## 用户入口

个人中心分别展示学生资格、独立实名、手机号与 QQ 绑定状态。用户可以发起认证、查看结果，并申请撤销或删除学生认证，由管理员处理。两种认证的状态分别展示。

有效校园资格包括普通认证、已认证校友和未过期的临时新生。普通认证长期有效，群接纳范围及各业务动作条件由对应配置决定。一个账号可以保留多段学习经历。

## 模块协作

业务模块按[动作资格配置](action-eligibility.md)检查服务提供的资格结论。服务不可用时，需要该结论的操作返回暂不可用，不将未知结果视为通过或失败认证。

用户已有内容与权益按相应业务规则保留。认证服务不直接修改评价、资料、账户或群成员数据，而是提供授权范围内的状态变化，由各业务处理。

## 私有规格

完整认证方法、材料处理、身份归属与核验规则维护在 [私有学生认证规格](https://github.com/StuHelper/stuhelper-verification/blob/docs/import-module-design/docs/spec/student-verification.md)。本页保留公共业务所需说明，不重复保存具体认证方案。
