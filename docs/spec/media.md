# 文件与媒体模块

## 数据与接口

media 拥有上传会话、对象版本、完整性摘要、内容类型、可用状态和业务引用。resources 拥有资料描述、作品许可、访问权益和发布决定；profiles 等模块通过文件引用使用媒体。

上传依次经历已创建、传输中、待校验、可引用、已引用、已取消或已过期。完成校验包括实际大小、摘要、允许类型和来源约束。需要审核的业务先保存待审引用，审核通过后开放对应使用。类型和容量参数由后台配置，配置完整后开放上传。

## 引用与下载

业务提交使用上传会话和引用操作 ID，重复提交返回同一引用。模块释放引用时 media 检查其他有效引用，无引用对象按清理任务删除。删除原始业务内容同时撤销相关下载入口。

受限文件使用私有对象存储，下载签发前由业务模块提供当前访问结论。签名期限、临时对象和取消重试按[模块通信规格](module-protocol.md)执行。下载名称保留用户原始文件名并安全编码，响应类型由已校验元数据确定。

## 存储与运营

存储后端以独立适配模块接入。BHpan 由私有 storage-bhpan 提供协议库，media 定义业务所需的存储接口，backend 负责注入实现。media 不依赖学校适配模块或私有实现类型；当前统一接口与正式装配尚未实施。

存储适配与贡献使用[存储贡献规则](storage-contribution.md)。媒体服务返回稳定状态和脱敏错误，业务模块据此反馈上传、校验和交付结果。文件不可用与用户无权访问分别处理。

| 场景 | 预期结果 |
| --- | --- |
| MEDIA-01 | 上传完成请求重试时，产生同一引用结果 |
| MEDIA-02 | 文件校验失败时，保持隔离状态并报告原因 |
| MEDIA-03 | 删除一个引用时，其他有效引用仍可使用对象 |
| MEDIA-04 | 文件被停用后，签发入口立即停止，现有签名按期限失效 |
