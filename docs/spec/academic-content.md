# 课程、教师与评价

## 范围与适用情况

本文定义课程、教师、开课与评价的行为。课程查询、互动、阅读和发布条件、作者展示及五级评分规则已确认，其余问题在文末列出。概念与关系见[内容设计](../design/academic-content.md)，资料规则见[资料规格](resource-sharing.md)。

## 术语与数据规则

| 对象 | 定义与约束 |
| --- | --- |
| School / Department / Term | 学校、院系、学期由 campus 模块管理；课程/学期代码不作全局 ID |
| Course | 学校内长期课程对象，稳定 ID、课程代码/别名、名称、学分及来源；改名保留历史 |
| CourseOffering | 某课程、某学期、某教学班的一次开设；允许同课程同学期多班 |
| Teacher | 可被关联和评价的教师档案，不以登录账号存在为前提；同名不自动合并 |
| TeachingAssignment | 开课与教师的授课关联，包含授课角色并保留变更历史，支持合授 |
| CourseReview | 对一次开课的课程体验评价，聚合到课程，可按学期/教师筛选 |
| TeacherReview | 对一次授课关系的教师评价，保留具体开课上下文并聚合到教师 |
| Resource | 课程资料，可选关联学期、开课与教师；无法判断的历史关联保持未知 |
| ResourceVersion | 同一资料的文件版本，具体维护与下载规则见资料规格 |

历史课程评价若缺少开课上下文，保留未知或待核实关联，不伪造开课。同名课程和教师不直接视为同一对象。具体旧数据迁移留给后续方案。

## 可观察行为

课程页提供基本信息、各学期开课、授课教师、课程评价和资料；教师页提供简介、按学期的开课列表、教师评价及相关资料；开课页展示具体教学班、合授教师及对应内容。支持按学校、院系、学期、教师等条件查找课程。

学分、院系、上课地点等信息缺失时显示“未提供”。例如学分未知时显示“学分未提供”，因为零学分有不同的业务含义。页面分别说明无内容、加载失败、无权限和内容已下架。

## 评课阅读与发布

| 用户状态 | 评课阅读 |
| --- | --- |
| 游客 | 可以查课程、教师和评课预览；隐藏评课标题，正文只展示受长度限制的首个非空行 |
| 登录但未完成学生认证 | 标题可见，正文仅展示受预览长度及比例限制的首个非空行 |
| 已认证学生 | 可以阅读完整评课 |

课程评价与教师评价的发布条件相同：用户已登录、学生认证通过且已绑定手机号。独立实名认证和选课记录均为非必需条件。发布时仍需选择被评价的课程、教师或开课。北航学生认证与实名状态的关系见[认证规格](student-verification.md)。预览长度与比例的具体数值尚未确定。

## 作者展示与发布后修改

课程评价和教师评价默认匿名。作者也可以主动选择署名，署名使用平台昵称和头像，认证真实姓名保持私密。匿名评价面向其他普通用户隐藏账号身份。管理员按[信息查询](information-query.md)和内容管理的授权范围查看关联记录。

评价发布后，作者不能直接编辑或删除。需要更正或撤回时提交修改或删除申请，由管理员处理并反馈结果；申请提交本身不改变已经发布的内容。发布前草稿仍可由作者编辑。

## 互动与个人内容

评课支持回复、点赞或点踩，投票可切换或取消。用户可收藏课程、举报评课、保存草稿继续编辑，并在个人中心查看我的评课、课程收藏和草稿。本规格中的收藏对象为课程。

页面应分别反馈草稿保存和评价发布的结果。保存失败时保留用户输入并说明原因。草稿数量、跨端保存与编辑冲突的处理方式仍待确认。

## 评分展示

保留五级文字与表情的定性展示，不向用户展示精确评分数字。旧版的推荐度文案为“强烈不推荐、不推荐、一般、推荐、强烈推荐”，通用表情语义为“很差、较差、一般、不错、超赞”。后续设计沿用五级表达，具体评分维度和图形样式另行确认。

课程评价与教师评价保留各自对象和上下文，不混成无法区分的一个评分。统计可显示样本量和时间范围；没有评价与评分较低是不同状态。

## 验收场景

| 场景 | 初始条件与动作 | 预期结果 |
| --- | --- | --- |
| ACAD-01 | 同课程两个学期、不同教师，查看课程和教师页 | 课程聚合历次开课，教师仅关联其授课记录，评价上下文保留 |
| ACAD-02 | 同一教学班由两位教师合授 | 一个开课对象包含两条授课关系，教师评价各自关联准确对象 |
| ACAD-03 | 同名不同学校教师，或课程学分缺失 | 不自动合并教师，缺失学分显示未提供而不是零 |
| ACAD-04 | 游客或未认证用户查看评课 | 按对应预览规则展示，不显示完整正文 |
| ACAD-05 | 已认证学生、已绑定手机但未独立实名，发布评课 | 不要求额外独立实名 |
| ACAD-06 | 课程或教师页面展示评价统计 | 使用五级文字和表情，不显示精确评分数字 |
| ACAD-07 | 用户将点赞改为点踩或取消投票 | 展示最终选择，不同时保留两种相反投票 |
| ACAD-08 | 从个人中心打开课程收藏、本人评课或草稿 | 可继续查询和编辑草稿；已发布评价通过申请修改或删除 |
| ACAD-09 | 发布课程评价或教师评价，未主动选择署名 | 默认匿名展示，不公开发布者账号 |
| ACAD-10 | 作者对已发布评价提出修改或删除申请 | 等待管理员处理，申请提交不直接改变内容 |
| ACAD-11 | 已认证学生且已绑定手机，无对应教师选课记录，发表教师评价 | 不以缺少系统选课证明阻止发布 |
| ACAD-12 | 作者主动选择署名 | 展示平台昵称和头像，保持认证真实姓名私密 |

## 待确认事项

发布后更换匿名或署名状态的处理、评分维度、评价数量限制、举报细节、互动资格及教师评价的阅读规则尚待确认。审核操作见[内容运营](content-management.md)，热门课程、教师和趋势见[内容发现](discovery-and-statistics.md)。
