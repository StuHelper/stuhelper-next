# 课程、教师、评价与资料

## 范围与适用情况

定义校园内容的目标行为，供用户查询、贡献和管理使用。当前没有业务 API 或数据库 migration；概念与关系图见[内容设计](../design/academic-content.md)。

## 术语与数据规则

| 对象 | 定义与约束 |
| --- | --- |
| School / Department / Term | 学校、院系、学期由 campus 模块管理；课程/学期代码不作全局 ID |
| Course | 学校内长期课程对象，稳定 ID、课程代码/别名、名称、学分及来源；改名保留历史 |
| CourseOffering | 某课程、某学期、某教学班的一次开设；允许同课程同学期多班 |
| Teacher | 可被关联和评价的教师档案，不以登录账号存在为前提；同名不自动合并 |
| TeachingAssignment | 开课与教师的授课关联，包含授课角色并保留变更历史，支持合授 |
| CourseReview | 对一次开课的课程体验评价，聚合到课程，可按学期/教师筛选 |
| TeacherReview | 对一次授课关系的教师评价，保留具体开课上下文并聚合到教师 |
| Resource | 课程资料，可选关联学期、开课与教师；无法判断的历史关联保持未知 |
| ResourceVersion | 不可变文件版本，记录贡献者、来源/许可、校验值、审核与访问范围 |

历史课程评价若缺少开课上下文，使用显式历史类型或待核实关联，不伪造开课。导入保留旧 ID 映射、原始时间、来源与归属证据；同名课程、教师或用户邮箱均不足以自动合并。

## 可观察行为

课程页提供基本信息、各学期开课、授课教师、课程评价和资料；教师页提供简介、按学期的开课列表、教师评价及相关公开资料；开课页展示具体教学班、合授教师及对应内容。

课程和教师评分分别定义维度及版本，统计显示样本量和时间范围，排除已删除、审核撤下或不满足计入规则的评价。评价编辑不得改成另一课程/教师来转移历史统计，编辑与撤回需保留必要审计。

上传文件先进入隔离状态，大小/类型/恶意内容检查和必要审核通过后才可供发布内容引用。对象存储为私有，下载每次复核权限并签发短期访问地址；资料需具备来源、许可、版本和下架/申诉入口。

页面区分无内容、加载失败、无权限和内容已下架。搜索、计数和缓存不得延长已撤销权限；私有资料不因被公开课程引用而变成公开。

## 验收场景

| 场景 | 初始条件与动作 | 预期结果 |
| --- | --- | --- |
| ACAD-01 | 同课程两个学期、不同教师，查看课程和教师页 | 课程聚合历次开课，教师仅关联其授课记录，评价上下文保留 |
| ACAD-02 | 同一教学班由两位教师合授 | 一个开课对象包含两条授课关系，教师评价各自关联准确对象 |
| ACAD-03 | 导入同名不同学校教师、未知年份资料 | 不合并教师、不伪造年份，保留来源与待核实信息 |
| ACAD-04 | 文件尚未扫描完成或已被下架，尝试下载 | 拒绝访问，原对象与审计按保留规则处理 |
| ACAD-05 | 已发布评价被审核撤下 | 正文不可见，后续可见评分统计不再计入；投影更新可追踪 |
| ACAD-06 | 用户无资料权限，从搜索或社交引用进入 | 各入口均不披露文件与受限元数据 |

## 待确认事项

评价资格、实名/匿名、编辑期限、具体评分维度和一用户一开课的有效评价数量尚待产品决定。需将确认后的规则落实到数据库约束与验收用例，不能先实现猜测的策略。治理行为见[社交与内容治理](social-content.md)。
