# 课程、教师与评价

## 范围与适用情况

定义课程、教师、开课与评课的目标行为。课程查询、互动、阅读门槛和五级评分展示已由 owner 确认；其余未决项在文末列出。当前没有业务 API；概念与关系图见[内容设计](../design/academic-content.md)，资料完整规则见[资料规格](resource-sharing.md)。

## 术语与数据规则

| 对象 | 定义与约束 |
| --- | --- |
| School / Department / Term | 学校、院系、学期由 campus 模块管理；课程/学期代码不作全局 ID |
| Course | 学校内长期课程对象，稳定 ID、课程代码/别名、名称、学分及来源；改名保留历史 |
| CourseOffering | 某课程、某学期、某教学班的一次开设；允许同课程同学期多班 |
| Teacher | 可被关联和评价的教师档案，不以登录账号存在为前提；同名不自动合并 |
| TeachingAssignment | 开课与教师的授课关联，包含授课角色并保留变更历史，支持合授 |
| CourseReview | 对一次开课的课程体验评价，聚合到课程，可按学期/教师筛选 |
| TeacherReview | 对一次授课关系的教师评价，保留具体开课上下文并聚合到教师 |
| Resource | 课程资料，可选关联学期、开课与教师；无法判断的历史关联保持未知 |
| ResourceVersion | 同一资料的文件版本，具体维护与下载规则见资料规格 |

历史课程评价若缺少开课上下文，保留未知或待核实关联，不伪造开课。同名课程和教师不直接视为同一对象。具体旧数据迁移留给后续方案。

## 可观察行为

课程页提供基本信息、各学期开课、授课教师、课程评价和资料；教师页提供简介、按学期的开课列表、教师评价及相关资料；开课页展示具体教学班、合授教师及对应内容。支持按学校、院系、学期、教师等条件查找课程。

学分、院系、上课地点等信息缺失时显示“未提供”或相应未知状态，不以零学分、默认院系等虚构内容填充。页面区分无内容、加载失败、无权限和内容已下架。

## 评课阅读与发布

| 用户状态 | 评课阅读 |
| --- | --- |
| 游客 | 可以查课程、教师和评课预览；隐藏评课标题，正文只展示受长度限制的首个非空行 |
| 登录但未完成学生认证 | 标题可见，正文仅展示受预览长度及比例限制的首个非空行 |
| 已认证学生 | 可以阅读完整评课 |

发布评课需要登录、学生认证通过和绑定手机号，不额外要求独立实名认证。资格与北航实名联动以[认证规格](student-verification.md)为准；预览长度与比例的具体数值尚未确定。

## 互动与个人内容

评课支持回复、点赞或点踩，投票可切换或取消。用户可收藏课程、举报评课、保存草稿继续编辑，并在个人中心查看我的评课、课程收藏和草稿。收藏对象是课程，不把旧业务自动扩展为另一套评课收藏规则。

草稿保存与发布结果应能让用户理解，保存失败不能伪报成功。草稿数量、跨端保存与冲突处理细节留待产品设计，不直接继承旧单槽实现。

## 评分展示

保留五级文字与表情的定性展示，不向用户展示精确评分数字。旧版的推荐度文案为“强烈不推荐、不推荐、一般、推荐、强烈推荐”，通用表情语义为“很差、较差、一般、不错、超赞”。后续设计沿用五级表达，具体评分维度和图形样式另行确认。

课程评价与教师评价保留各自对象和上下文，不混成无法区分的一个评分。统计可显示样本量和时间范围；没有评价与评分较低是不同状态。

## 验收场景

| 场景 | 初始条件与动作 | 预期结果 |
| --- | --- | --- |
| ACAD-01 | 同课程两个学期、不同教师，查看课程和教师页 | 课程聚合历次开课，教师仅关联其授课记录，评价上下文保留 |
| ACAD-02 | 同一教学班由两位教师合授 | 一个开课对象包含两条授课关系，教师评价各自关联准确对象 |
| ACAD-03 | 同名不同学校教师，或课程学分缺失 | 不自动合并教师，缺失学分显示未提供而不是零 |
| ACAD-04 | 游客或未认证用户查看评课 | 按对应预览规则展示，不显示完整正文 |
| ACAD-05 | 已认证学生、已绑定手机但未独立实名，发布评课 | 不要求额外独立实名 |
| ACAD-06 | 课程或教师页面展示评价统计 | 使用五级文字和表情，不显示精确评分数字 |
| ACAD-07 | 用户将点赞改为点踩或取消投票 | 展示最终选择，不同时保留两种相反投票 |
| ACAD-08 | 从个人中心打开课程收藏、本人评课或草稿 | 进入对应内容，能够继续查询或编辑 |

## 待确认事项

作者对外匿名或署名、编辑与撤回规则、评分维度、评价数量限制、举报细节、互动资格及教师评价是否完全沿用评课门槛尚待确认。不能把“不要求独立实名”理解为已经选择匿名展示，也不能把学生资格门槛扩成“必须修过该课程”。治理提案见[社交与内容治理](social-content.md)。
