# 课程、教师与评价

## 范围与适用情况

本文定义课程、教师、开课与评价的行为。课程评价使用五个评分维度，教师评分汇总其所授课程的课程评价。导师评价采用文字评论和可编辑推荐模板，不设评分。阅读、发布、互动和作者身份规则见下文。概念与关系见[内容设计](../design/academic-content.md)，资料规则见[资料规格](resource-sharing.md)。

## 术语与数据规则

| 对象 | 定义与约束 |
| --- | --- |
| School / Department / Term | 学校、院系、学期由 catalog 模块管理；课程/学期代码不作全局 ID |
| Course | 学校内长期课程对象，稳定 ID、课程代码/别名、名称、学分及来源；改名保留历史 |
| TermCourse | 某课程在某学期的开课，按 `(course_id, term_id)` 唯一；同学期多个教学班共享一个学期开课对象 |
| TeachingClass | 某个 TermCourse 下的教学班，保存班级代码及来源；未知班级不伪造 |
| Teacher | 可关联授课关系与导师评论的教师档案，不以登录账号存在为前提；同名不自动合并 |
| TeachingAssignment | 教学班与教师的授课关联，包含授课角色并保留变更历史，支持合授 |
| CourseReview | 对课程本身或相关授课体验的评价，可补充学期开课、教学班和教师信息，聚合到课程 |
| MentorReview | 针对导师指导的文字评论，使用研究生指导推荐模板，不设置评分维度 |
| TeacherScore | 从教师所授课程的有效课程评价派生的教师评分，没有独立教师评价入口 |
| Resource | 课程资料，可选关联学期、开课与教师；无法判断的历史关联保持未知 |
| ResourceVersion | 同一资料的文件版本，具体维护与下载规则见资料规格 |

历史课程评价若只有课程和学期，可关联 `TermCourse`，教学班保持未知。缺少学期时只关联课程，不伪造开课或教学班。同名课程和教师不直接视为同一对象。本次重构不迁移旧课程评价，未知关联规则用于新系统之后的录入和维护。

## 可观察行为

课程页提供基本信息、各学期开课、授课教师、课程评价和资料；教师页提供简介、按学期的开课列表、教师评分、导师评价及相关资料；学期开课页展示该学期各教学班、对应教师及内容，教学班详情保留自己的合授关系与课表上下文。支持按学校、院系、学期、教师等条件查找课程。

学分、院系、上课地点等信息缺失时显示“未提供”。例如学分未知时显示“学分未提供”，因为零学分有不同的业务含义。页面分别说明无内容、加载失败、无权限和内容已下架。

## 评价阅读与发布

课程评价与导师评价采用相同的初始阅读规则。阅读、发布和互动资格均可通过[动作资格配置](action-eligibility.md)调整。

下文的已认证学生包含通过普通认证的在校学生、已认证校友和有效期内的临时新生，完整定义见[认证规格](student-verification.md)。

| 用户状态 | 评课阅读 |
| --- | --- |
| 游客 | 可以查课程、教师和评课预览；隐藏评课标题，正文只展示受长度限制的首个非空行 |
| 登录但未完成学生认证 | 标题可见，正文仅展示受预览长度及比例限制的首个非空行 |
| 已认证学生 | 可以阅读完整评课 |

课程评价与导师评价的发布条件相同：用户已登录、学生认证通过且已绑定手机号。独立实名认证和选课记录均为非必需条件。用户可以只针对课程本身发表，也可以选择所评教师并说明相应授课体验。游客与未认证登录用户的预览字数分别由后台配置，比例限制也通过预览配置管理。

不按用户、课程、教师、学期或教学班设置评价条数上限。同一用户可以针对不同教师或课程本身分别发表，也可以再次补充新的评价。重复发送同一次提交只产生一条评价。

普通评价和回复默认提交后发布。规则命中时可以拦截、发布后标记复核，或转为审核通过后发布。管理员可按内容类型配置审核方式，完整规则见[内容管理](content-management.md)。

## 作者展示与发布后修改

课程评价和导师评价默认匿名。作者也可以主动选择署名，署名使用平台昵称和头像，认证真实姓名保持私密。匿名评价面向其他普通用户隐藏账号身份。管理员按[信息查询](information-query.md)和内容管理的授权范围查看关联记录。

回复也默认匿名，并允许用户选择署名。评价作者的回复沿用评价的身份，其他用户在首次回复时确定身份。同一用户在同一评价下的后续回复保持相同身份，撤回重编也不改变身份。

管理员提供快捷的匿名与署名切换操作，用户侧不提供切换申请入口。切换统一作用于该用户在整条讨论中的身份及全部回复。这里的署名仍表示平台昵称和头像，不公开认证真实姓名。

课程评价、导师评论和回复提供撤回重编能力，初始窗口为首次公开发布后的 5 分钟，允许后台配置。撤回或重新发布均不刷新起算时间。

撤回成功后，原位置显示“作者已撤回，正在修改”，正文暂时隐藏。原条目、已有回复和投票保留。用户可以继续编辑，不要求在剩余倒计时内完成；重新提交仍按当前资格和审核规则处理，通过后更新原条目。

作者不能自行删除内容。超出窗口后不能新发起撤回，其他修改和删除通过申请由管理员处理。已经在窗口内撤回的内容可以继续编辑并重新提交。草稿仍可由作者自行编辑。

## 互动与个人内容

评课支持回复、点赞或点踩，投票可切换或取消。用户可收藏课程、举报评课、保存草稿继续编辑，并在个人中心查看我的评课、课程收藏和草稿。本规格中的收藏对象为课程。

回复需要有效学生资格和已绑定手机号。点赞、点踩、收藏和举报只要求登录，不额外要求学生认证或手机号。

页面应分别反馈草稿保存和评价发布的结果。保存失败时保留用户输入并说明原因。允许保存多份草稿，登录后跨端同步。出现编辑冲突时提示用户选择保留版本，不静默覆盖另一端内容。

同一用户对同一内容只保留一份处理中举报，允许补充证据。管理员结案后，用户可以基于新事实再次举报。

## 课程评分

课程采用以下五个评分维度，后台可分别配置展示文案：

| 维度 | 说明 |
| --- | --- |
| 推荐度 | 是否推荐其他同学选择这门课程 |
| 内容质量 | 课程内容的质量与学习价值 |
| 课程难度 | 理解和掌握课程内容的难易程度 |
| 工作量 | 作业、实验、项目等学习任务的工作量 |
| 考核给分 | 考核方式与给分体验 |

继续采用五级文字与表情，不向用户展示精确评分数字。推荐度文案沿用“强烈不推荐、不推荐、一般、推荐、强烈推荐”。难度和工作量使用各自对应的程度表达，避免将“难”或“工作量大”直接表示成质量差。具体图形与各级文案在界面设计中确定。

统计可以展示样本量和时间范围。没有评价与评分较低分别展示。

## 教师评分与主页

教师主页列出该教师教授过的全部课程，并展示每门课程的五维均分结果。教师评分先分别计算每门课程的有效评价均值，再对有有效样本的课程等权平均，不按评价数量给热门课程更高权重。同一课程跨学期开设多次时仍作为一门课程参与平均。

课程均分使用该课程全部当前可见的有效评价，包括未指定教师的课程评价。课程无有效样本时显示暂无足够数据，不用零分参与教师平均。页面显示课程数、评价样本量和统计范围，均分展示仍遵循五级文字与表情规则。教师没有单独评价入口，导师评论不参与教师评分。

## 导师评论模板

导师评价不提供评分维度，也不计入教师评分。教师评分仅从所授课程的课程评价汇总，教师主页同时展示这两部分。进入导师评论编辑器时，默认加载以下推荐模板：

```text
导师的指导风格

对博士生的要求

对硕士生的要求

经费和支持

科研

实验室氛围
```

模板是可自由编辑的正文，用户可以修改、删去部分段落或删除整个模板后自行撰写。模板中的六个主题不是必填字段，不据此要求用户同时具有博士生和硕士生经历。

## 验收场景

| 场景 | 初始条件与动作 | 预期结果 |
| --- | --- | --- |
| ACAD-01 | 同课程两个学期、不同教师，查看课程和教师页 | 课程聚合历次开课，教师仅关联其授课记录，评价上下文保留 |
| ACAD-02 | 同一教学班由两位教师合授 | 一个学期开课下的同一教学班包含两条授课关系，课程评价保留所选教师，导师评论另行关联导师档案 |
| ACAD-03 | 同名不同学校教师，或课程学分缺失 | 不自动合并教师，缺失学分显示未提供而不是零 |
| ACAD-04 | 游客或未认证用户查看评课 | 按对应预览规则展示，不显示完整正文 |
| ACAD-05 | 已认证学生、已绑定手机但未独立实名，发布评课 | 不要求额外独立实名 |
| ACAD-06 | 课程页面展示评分统计 | 按五个课程维度使用文字和表情，不显示精确评分数字 |
| ACAD-07 | 用户将点赞改为点踩或取消投票 | 展示最终选择，不同时保留两种相反投票 |
| ACAD-08 | 从个人中心打开课程收藏、本人评课或草稿 | 可继续查询和编辑草稿；已发布内容按撤回窗口或管理员申请流程处理 |
| ACAD-09 | 发布课程评价或导师评价，未主动选择署名 | 默认匿名展示，不公开发布者账号 |
| ACAD-10 | 作者对已发布评价提出修改或删除申请 | 等待管理员处理，申请提交不直接改变内容 |
| ACAD-11 | 已认证学生且已绑定手机，无对应教师选课记录，发表导师评价 | 不以缺少系统选课证明阻止发布 |
| ACAD-12 | 作者主动选择署名 | 展示平台昵称和头像，保持认证真实姓名私密 |
| ACAD-13 | 同一用户对同一课程或教师再次发表新评价 | 不因已经发表过评价而拒绝；同一次请求的重复发送仍只产生一条 |
| ACAD-14 | 用户只评价课程本身 | 可发表课程评价，不要求同时选择教师 |
| ACAD-15 | 登录但未认证用户点赞、收藏或举报 | 可完成操作；发布回复仍需学生资格和手机号 |
| ACAD-16 | 游客查看导师评价 | 与课程评价采用相同预览规则 |
| ACAD-17 | 用户进入导师评论编辑器 | 加载六段推荐模板，不出现导师评分输入 |
| ACAD-18 | 用户删除导师模板后自行撰写 | 可以正常提交，不要求补齐六个主题 |
| ACAD-19 | 同一用户继续回复同一评价 | 沿用该讨论中的身份，用户不能自行切换 |
| ACAD-20 | 用户希望将已发布内容切换匿名或署名 | 不提供公开申请入口，管理员通过管理操作处理 |
| ACAD-21 | 首次公开发布后 4 分钟撤回，10 分钟后重新提交 | 可完成重编并按审核规则重新发布，更新原条目，已有回复与投票保留 |
| ACAD-22 | 撤回后重新发布，再次请求撤回时已超过首次发布时间 5 分钟 | 不重新计算窗口，不能新发起撤回 |
| ACAD-23 | 管理员切换某用户在一条评价中的匿名状态 | 该用户在这条讨论中的身份和全部回复统一更新，其他讨论不受影响 |
| ACAD-24 | 同课程同学期有两个教学班 | 只有一个 TermCourse，下面有两个 TeachingClass，各班教师与课表分别关联 |
| ACAD-25 | 同一课程下一学期再次开设 | 新建 TermCourse，原学期的班级、授课和评价关联保留 |
| ACAD-26 | 历史评价仅知道课程与学期 | 关联 TermCourse，教学班保持未知，不据教师或课程名称猜测 |

## 配置与后续事项

教师评分已确定为先算课程均分，再对课程等权平均。预览参数可配置，多份跨端草稿与处理中举报合并规则已确认。审核操作见[内容运营](content-management.md)，热门课程、教师和趋势见[内容发现](discovery-and-statistics.md)。
