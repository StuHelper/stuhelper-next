# 我的课程与课表

## 范围

该业务已确认保留：用户查看本人某学期课程、授课教师、上课时间和地点，并进入相关课程内容。旧项目提供学校数据读取与展示，本次没有确认选课、退课、排课或成绩写入业务。

## 目标行为

用户可从个人中心进入我的课程，按学期查看课程列表和课表。每条课程保留能够取得的课程、教学班、教师、时间、地点信息；缺失字段显示未提供，不把未知时间或地点编造为默认值。

能够关联到课程目录时，用户可继续查看课程详情、评价和资料；能够关联到教师时，可进入教师开课列表。关联尚未建立时仍能理解学校提供的课程记录，不因缺少平台教师档案而隐藏整门课程。

页面区分尚无课程数据、该学期确无课程以及数据加载失败。页面显示来源与更新时间。用户可导入已接入的学校课程，也可手动添加和更正个人课程。个人修改作用于本人日程。评课资格采用可信教务导入的选课记录，个人日程与选课证据分别保存。

保留历史学期，支持按学期查看周课表、导出日历与可选上课提醒。导入与现有个人修改冲突时，由用户选择保留或替换，不能静默覆盖。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| MC-01：本人当前学期存在课程 | 展示课程、教师和已知时间地点，支持课程与课表视图 |
| MC-02：切换学期 | 展示所选学期，不混入其他学期的课程 |
| MC-03：课程未关联到平台教师或缺少地点 | 保留已有课程信息，未知项明确显示 |
| MC-04：学校数据暂不可用 | 说明数据状态，不把故障显示成用户没有选课 |

## 配置与后续事项

学校按实际接入能力开放，同步频率由后台配置。日历格式、提醒提前量与课表冲突的界面呈现由实现设计按已确认业务规则确定。
