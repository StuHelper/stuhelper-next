# Agent 助手与 MCP

## 范围与适用情况

本文定义对话首页、语音、Agent 授权、工具调用和 MCP 的目标行为，当前尚未实现。进度见[实施记录](../development/ai-native.md)，机制见 [AI native 架构](../design/ai-native-architecture.md)。

## 首页与对话

首页以对话框为中心，通过内容准入的用户默认看到今日课程和近期 DDL 卡片。课表、教师对比和确认操作使用可信组件显示，模型不能生成任意 HTML。回答引用的数据显示来源和更新时间，并能进入对应详情页。

页面处理加载、无数据、业务拒绝、网络错误和重试。发送失败时保留用户输入。文案覆盖八种语言，阿拉伯语按 RTL 显示，对话和卡片支持键盘操作和屏幕阅读器。

## 内容准入

Agent 和 MCP 遵守与页面相同的准入规则，规则见[动作资格配置](action-eligibility.md)。当前只服务北京航空航天大学，查询课程、教师、评价和资料须完成北航学生或教师认证。这项检查与 Agent 授权相互独立。

未登录、未认证、认证处理中和认证失效的用户不能调用内容工具。认证失效的用户仍可按 Agent 授权使用本人记录工具，例如查询本人课程和 DDL。内容工具不可用时，首页分别显示登录、认证或认证进度入口。资格读取失败时内容保持关闭并提供重试，不说成认证失效。

通过准入的用户按账号设置对话额度。额度用尽时说明原因，业务页面继续可用。

## Agent 授权

| 数据类别 | 例子 | 规则 |
| --- | --- | --- |
| 准入内容 | 课程目录、教师开课、评分等级、评价和资料正文 | 无需 Agent 授权，但必须通过内容准入，且不超出账号当前阅读权限 |
| 本人日常数据 | 课表、DDL、个人日程、对话记忆 | 默认关闭，按类别授权 |
| 本人敏感数据 | 姓名、学号、手机号、钱包记录 | 默认关闭，逐项授权 |
| 禁止数据 | 匿名评价作者、他人资料、认证材料、证件、凭据和密钥 | 不提供工具，用户也不能授权 |

- Agent 首次需要某类数据时显示授权卡片，选项为仅本次、本次会话、始终允许和拒绝。
- “仅本次”只对当前这次提问有效。回答结束后，相关结果不再发给模型，用户仍能在对话记录中看到。
- 读取和写入分别授权。每个客户端的授权相互独立。
- 组合工具和派生结果需要全部来源数据的授权。例如 `find_free_time` 同时需要课表和个人日程授权。
- 缺少授权时，Agent 说明缺少哪项授权，不猜测答案。用户拒绝部分授权时，结果必须写明只覆盖哪些数据。

用户在个人中心查看授权和使用记录。撤销后，进行中的运行在下一次工具调用前被拒绝，相关待确认操作作废。

撤销后，已有工具结果及其摘要不再发给模型。评价下架或用户失去阅读权限时同样处理。已发给模型供应商或外部 MCP 客户端的数据无法由服务端收回，授权卡片要说明这一点。

## 工具与写操作

工具结果区分成功、无数据、未授权、依赖不可用和来源缺失，并包含来源和更新时间。列表工具设置分页和单页上限。工具不接受目标用户参数，只操作令牌对应的用户。

首期所有写操作都逐次确认，用户不能关闭。服务端保存待确认操作，绑定用户、客户端、工具、规范化参数、对象修订号和有效期。用户在 StuHelper 界面确认后，服务端执行所保存的参数，并重新检查权限。

模型或客户端提交的 `confirmed: true` 没有确认效力。参数变化时必须重新预览。确认过期、对象修订号变化或由其他客户端使用时，操作被拒绝。

评价、资料等他人撰写的内容及其摘要都标记为不可信内容。回复不渲染外部图片和未知链接。今后开放免确认操作时，必须先确保这一标记能跟随跨轮对话、会话摘要和长期记忆。

管理员信息查询和管理操作不提供 Agent 工具。Agent 不向学校系统执行选课、退课、排课或改成绩。

工具调用记录用户、客户端、渠道、工具、Agent 授权 ID、结果和耗时。日志不保存敏感字段的值。模型不能接触匿名评价的作者身份。

## 语音

语音输入把语音转为文字，发送前用户可以修改。实时通话支持用户打断。音频默认不保存，转写按对话记录处理。

通话中的写操作也要在屏幕上确认，因为语音识别可能听错日期或课程名。麦克风权限被拒绝或语音服务不可用时，用户可以继续使用文字。

## MCP

首期只开放用户本人的 MCP 客户端，并且只提供只读工具。用户登录后逐项授权，可随时撤销。MCP 使用与站内 Agent 相同的准入和权限检查，但不继承站内 Agent 的授权。令牌必须绑定 StuHelper MCP 服务，不转发给下游服务。

第三方应用上架不属于首期范围，继续走[开放平台](open-platform.md)审核。

## 记忆与保留

长期记忆只保存用户明确要求或确认保存的内容，并保留来源标记。用户可以查看、修改和删除记忆及对话。保存期和删除规则见[数据保留](data-retention.md)。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| AG-01：已授权课表的用户问明天的课 | 返回明天的课程、时间和地点，并显示来源和更新时间 |
| AG-02：未授权课表的用户问明天的课 | 显示授权卡片，不回答“没有课” |
| AG-03：用户撤销授权后再次提问 | 工具调用被拒绝，并记录拒绝结果 |
| AG-04：Agent 授权读取超出账号权限的内容 | 模块按账号权限拒绝，授权不能扩大权限 |
| AG-05：工具调用尝试指定其他用户 | 工具没有该参数，额外参数被拒绝 |
| AG-06：同一写操作因网络重试 | 只产生一次业务结果，并返回原结果 |
| AG-07：评价正文诱导 Agent 修改日程 | 写操作不会自动执行，用户确认前没有数据变化 |
| AG-08：评价正文诱导 Agent 输出外部图片链接 | 回复不加载该图片，不发送用户数据 |
| AG-09：模型不可用 | 首页说明状态，课程卡片和业务页面继续可用 |
| AG-10：catalog 不可用 | Agent 说明无法取得课表，不说成没有课 |
| AG-11：reviews 模块关闭 | 评价工具不再提供，其他工具继续可用 |
| AG-12：MCP 客户端未获授权 | 站内 Agent 的授权不适用，访问被拒绝 |
| AG-13：用户询问匿名评价的作者 | Agent 无法取得作者身份，并说明不能提供 |
| AG-14：涉及资金的操作 | 始终需要用户确认，用户设置不能跳过 |
| AG-15：语音识别结果需要写入日程 | 屏幕显示预览，确认后才写入 |
| AG-16：未登录、未认证或认证失效的用户通过 Agent 或 MCP 查询课程 | 拒绝并显示对应入口，不返回内容 |
| AG-17：资格读取失败 | 内容保持关闭并提供重试，不说成认证失效 |
| AG-18：用户授权个人日程但拒绝课表，询问是否有空 | 只回答个人日程中有无冲突，不回答“你有空” |
| AG-19：用户撤销课表授权后在原会话追问 | 旧课表结果及其摘要不再发给模型 |
| AG-20：评价下架后在原会话追问 | 该评价及其摘要不再发给模型 |
| AG-21：用户确认后参数被替换 | 拒绝执行并重新预览，数据没有变化 |
| AG-22：确认已过期、对象已变化或由其他客户端使用 | 拒绝执行，数据没有变化 |
| AG-23：同一确认重复提交 | 只执行一次，并返回原结果 |
| AG-24：模型或客户端提交 `confirmed: true` | 没有确认效力，操作不执行 |
| AG-25：恶意评价经跨轮对话、会话压缩或长期记忆再次出现 | 写操作仍需用户确认，确认前没有数据变化 |
| AG-26：MCP 客户端请求写工具 | 首期不提供写工具 |
| AG-27：撤销授权时存在待确认操作 | 待确认操作作废，之后不能执行 |
| AG-28：认证失效的用户已授权课表，询问明天的课 | 返回本人课程，课程详情和评价工具仍被拒绝 |
