# SSO 接入与应用会话

应用继续通过标准 OIDC 与官方 API 接入身份服务。按 issuer、subject 标识账号并保存消费方绑定，不以业务账号注销替代共享 SSO 账号删除。

注册、登录与找回由独立 SSO 提供。本应用当前设备和全部设备退出撤销本应用会话，其他应用按自身规则管理。原生公有客户端不保存 client secret。

身份服务使用官方发行原件。SSO 接入配置与运行维护见[私有接入规格](https://github.com/StuHelper/stuhelper-ops/blob/develop/docs/spec/sso-compatibility.md)。旧系统的 SSO、学生认证和 QQ 绑定数据在新系统完成后另行转换导入，开发阶段不提供兼容或导入结构。

## 服务端身份读取

服务端 Casdoor 调用使用必填 back_channel_url。配置只接受 loopback 或明确给出的私有 IP 地址，拒绝公网 IP 和主机名。issuer 校验和浏览器登录跳转继续使用公开 HTTPS 地址，内部通道覆盖发现、token、introspect、get-user 与 JWKS。

应用 client_credentials token 复用至过期前的安全余量。introspect 按 token 摘要缓存，期限为 min(令牌剩余有效期, 30 秒)；get-user 按 subject 缓存 30 秒。同键并发合并，缓存和不同键在途读取均有容量上限。

封禁、删除、上游撤权与 token 撤销最迟 30 秒生效。此时延由 Claude 代负责人于 2026-11-13 确定。失败不延长旧缓存。本地会话撤销及业务授权仍逐次执行，退出登录清理相关缓存，并阻止在途读取回填旧事实。

满槽请求在自身上下文内最多等待两秒，再返回不可用。诊断记录阶段、错误类别、耗时和 request_id，不记录 token、secret、完整 subject 或上游响应正文。

Web 与 Admin 合并会话检查。临时故障后的再次检查按 1、2、4 秒递增，最多等待 8 秒。页面保留有效输入并提供重试，业务写请求不自动重放，明确身份拒绝后清除会话展示。

## 应用会话验收

| 场景 | 预期结果 |
| --- | --- |
| SSO-01 | 登录回调只消费一次，写操作校验 CSRF 与当前学校范围，本地授权撤销后下一次操作拒绝，上游账号事实最长 30 秒生效 |
| SSO-02 | 本应用令牌在服务端加密保存，身份服务故障明确返回，全部设备退出撤销所有本应用会话 |
| SSO-03 | 应用重启保留有效会话，运行账号不能 DDL 或读取其他模块数据 |
| SSO-04 | 25 并发遇慢上游或暂时停顿时合并读取，缓存命中不访问上游，退出与过期按规定生效 |
| SSO-05 | 非内部配置被拒绝，超时与连接失败可通过脱敏诊断定位，客户端重试有退避且保留输入 |
