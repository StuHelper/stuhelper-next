# 收藏与收藏夹

favorites 独立拥有课程、教师、资料收藏和收藏夹。目标存在、种类、当前内容准入及可见状态通过所属模块公开接口校验，模块之间不直接访问对方数据库。

## 归属与展示

新增收藏要求内容准入。本人列表、取消、移动和收藏夹管理仅要求登录。资格失效后仍可管理本人记录，其他账号不能读取、移动或取消这些记录。

收藏回执只返回名称快照、目标 ID、种类、收藏夹、时间和修订。对象详情、评分、正文与文件仍通过原业务入口检查当前权限。目录已不存在的历史目标可以只保留 ID。

同一用户对同一目标只有一条收藏，每条收藏只属于一个夹。重复新增不改变所属夹，移动必须使用独立操作。删除普通收藏夹时保留全部收藏并移入默认夹，默认夹不能删除，可以改名。

收藏夹名称去掉首尾空白后不得重复，默认夹改名也适用。名称区分大小写，长度为 1 至 20 个 Unicode 码点。收藏夹使用稳定 ID，改名不改变归属。未自定义名称的默认夹使用客户端本地化标签。

## 接口与一致性

列表每页最多 100 条。收藏支持收藏夹、种类与名称筛选，提供新增时间和名称排序。游标绑定账号与筛选条件。收藏夹返回当前总条数，条数不受收藏列表筛选影响。

所有写操作使用幂等键，修改和删除同时检查修订。相同请求返回原结果，相同键不同内容或过期修订返回 409。业务写入、审计与幂等记录在同一事务中完成，数据库唯一约束防止重复收藏和重名。

## 验收场景

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| FAV-01 | 跨账号访问、认证失效、并发新增、重名、移动与删除 | 归属隔离，拒绝新增，允许本人管理，每个目标一条记录，收藏夹名称唯一 |

账号注销时删除本人收藏、所有收藏夹和相关幂等响应。保留最小关闭标记以阻止并发写入和请求重试恢复数据。删除与关闭标记同事务提交，失败可恢复，其他账号的收藏不受影响。
