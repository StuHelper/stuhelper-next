# 框架运行与应用入口

## 范围

本阶段提供可运行的公共平台、Web 与 Admin 工程。业务模块继续按已确认的规格在各自仓库实现。框架包含模块依赖检查、生命周期、HTTP 访问边界、远程模块接口核对、API 类型生成与开发工作区。

当前没有课程、认证、账务、群管理等业务实现，也没有数据库 schema、真实会话或数据迁移。所有业务入口在实现前保持不可用。

## 服务端组合

平台使用 Go 1.27.2、标准 HTTP 服务与 Uber Fx v1.24.0。模块导出 Definition，声明标识、构建版本、接口主版本、必需依赖和能力，再提供启动、停止及就绪检查。组合程序显式导入固定版本模块，调用 application.New 组装，不从网络下载并执行模块代码。

初始化先检查重复标识、能力归属、依赖存在性、接口主版本和循环。通过检查后按依赖顺序向 Fx 注册生命周期。启动失败时 Fx 逆序停止已经启动的模块，失败模块负责清理自己的部分初始化。停止时先关闭 HTTP 监听并排空请求，再逆序关闭模块。

首期模块启停通过配置和重启生效，不提供在线管理开关。移除仍被依赖的模块会在下次启动前报错。配置变化与停止不会触发数据删除或 schema 回退。业务需要在线启停时，在同一生命周期边界增加排空与管理接口。

## HTTP 与身份接口

公开 API 为存活、就绪和能力发现。能力列表只表示功能是否可用，不表示调用者有权限。模块路由必须明确声明公开或受保护访问，默认值不能注册。

受保护路由依次检查模块可用性、Authenticator 和 Authorizer。当前身份适配器未接入，因此管理接口返回 identity_unavailable。后续身份适配器在私有 SSO 仓库实现；领域规则与资源范围仍由具体模块的 Service 检查。

每次请求生成服务端 request ID。统一 JSON 错误不包含原始异常、身份、凭据或远程响应。HTTP 默认只监听 127.0.0.1:8080，可用 STUHELPER_LISTEN 配置；STUHELPER_MODULES 声明启用模块。当前公共二进制只安装 platform，填写尚未安装的模块会启动失败。

启动和停止总时限分别为 15 秒，HTTP 读取请求头为 5 秒，读取请求为 15 秒，写响应为 30 秒。请求体上限为 1 MiB，模块就绪检查共享每次请求的 2 秒预算。业务文件上传将由独立文件接口处理，不沿用普通 JSON 请求限制。

## 私有模块连接

私有模块通过配置的固定服务地址接入。框架检查 `/internal/v1/module` 返回的模块标识、接口主版本和预先声明的能力。远端不能增加本地未批准的能力或路由。

除 loopback IP 外连接必须使用 HTTPS，不跟随重定向，响应大小和等待时间有上限。可选服务凭据从部署提供的文件读取，不写入工作区清单。这里仅实现通用连接边界；认证判断、支付和学校协议仍在相应私有模块中实现。

## 契约与客户端

platform 仓库维护 OpenAPI 3.1，使用 oapi-codegen v2.8.0 与 openapi-typescript v7.13.0 生成 Go/TypeScript 类型。客户端保存可追溯的契约与生成类型快照，单仓库可独立检查。工作区检查必须确认提供方和两个客户端快照完全一致，不能手工修改生成类型。oasdiff v1.34.1 校验两份 OpenAPI，并对 PR 基线中已有接口执行破坏性变更检查。新接口先建立经校验的初始基线。

Web 使用 Vue 3、TypeScript、Vite 与 Vue Router。Admin 使用 Vben Admin 官方 v5.7.0 的默认 web-antd 应用，保留官方布局、主题和组件适配。Admin 内部共享组件保留 upstream 的 pnpm workspace 结构，这不改变业务模块分别建仓库的边界。Element Plus 不作为新 Admin 的选型。

客户端对请求超时、连接失败、接口主版本不兼容、登录缺失及权限拒绝提供明确状态。首期只提供应用空壳，不复制演示账号、统计值或交易数据来填充页面。

## 依赖与发布

Mani 管理本地检出与任务。Go Workspace 只参与本地多 Go 模块开发；各 Go 仓库的 CI 另外检查自身依赖。各前端仓库分别维护锁文件，Admin 继承 Vben 的指定 pnpm 版本。

当前使用显式 bootstrap 分支完成跨仓库 PR 验证，属于开发组合。正式发行仍需 owner 授权，各模块使用不可移动的版本 tag，ops 保存部署组合与摘要核验记录。不能把开发工作区的通过记录当成正式发行或生产验收。

## 验证与后续工作

框架验收覆盖依赖失败、生命周期回退、远程接口不兼容、权限拒绝、契约生成一致性、客户端构建和真实 HTTP 联调。结果由[框架工作记录](../development/framework-bootstrap.md)维护。

持久化、outbox、真实会话、动作资格策略、业务数据迁移和发布流水线随对应业务模块接入，必须增加各自的测试与验收。统一的库接口不能替代这些业务实现。
