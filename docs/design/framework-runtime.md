# 框架运行与应用入口

## 当前范围

platform 提供模块组合、HTTP 边界、契约和远程服务连接。Web 与 stuhelper-admin 提供八语言入口、状态展示与错误恢复。业务 API、持久化、真实身份和数据迁移随各业务仓库实施，进度见[框架状态](../development/framework-bootstrap.md)。

## 服务端组合与依赖

平台使用 Go、标准 HTTP 服务和 Uber Fx。模块导出 Definition，声明模块标识、接口主版本、必需依赖、可选依赖和能力。组合程序显式导入模块并交给 application.New。

Registry 校验业务依赖并确定顺序，Fx 管理启动、回退、停止和进程退出。两者分别处理模块规则与进程生命周期。初始化检查重复标识、能力归属、依赖版本和必需依赖环。存在的可选依赖也须满足声明的接口版本。

必需依赖影响模块基础可用性。可选依赖缺失或暂时不可用时，仅停止在 CapabilityRequires 中声明需要它的能力。例如评价浏览可以继续运行，需要资格结论的发布操作返回暂不可用。

启动失败时 Fx 逆序停止已经启动的模块，失败模块清理自己的部分初始化。停止时先关闭 HTTP 监听并排空请求，再逆序停止模块。启停通过配置和重启生效，数据生命周期由各模块规格管理。

## 健康与远程服务

远程服务连接核对 `/internal/v1/module` 的标识、接口主版本和已批准能力。首轮探测最多等待 200 毫秒；配置、凭据或已识别的协议不兼容使启动失败，网络超时和服务暂时不可达使相关能力进入不可用状态。后台探测继续确认初次超时的服务。

后台默认每 3 秒探测一次，连续失败时退避至最多 30 秒。请求读取健康快照，快照有效期为两倍探测间隔加单次超时。服务凭据文件由探测过程重新读取，支持文件替换后的凭据轮换。探测和服务停止共享可取消的生命周期，公开流量不会增加远程探测次数。

生命周期状态与健康状态分别报告。`/readyz` 检查组合显式声明为 Critical 的模块及其必需依赖；platform 为关键模块。业务服务故障通过能力列表和管理状态呈现，需要该服务的路由返回 `module_unavailable`。

远程连接除 loopback IP 外使用 HTTPS，固定服务地址，拒绝重定向，限制响应大小与等待时间。远端元信息只能确认本地已批准能力。

## HTTP 与身份接口

路由显式声明模块、能力和公开或受保护访问。受保护路由检查能力、Authenticator 和 Authorizer，具体资源权限继续由业务 Service 判断。当前身份适配器尚未接入，管理接口返回 `identity_unavailable`。

平台生成 request ID，统一错误响应隐藏原始异常、凭据和远程响应。响应开始前的 panic 返回结构化 500，响应开始后的 panic 中止连接。默认监听 `127.0.0.1:8080`，由 `STUHELPER_LISTEN` 调整；`STUHELPER_MODULES` 声明启用模块。

启动与停止预算各为 15 秒，读取请求头为 5 秒、请求为 15 秒、写响应为 30 秒。普通 JSON 请求体上限为 1 MiB。能力检查共享最多 2 秒预算，本地 Ready 钩子应为快速内存检查，远程钩子读取缓存。文件上传使用独立接口。

## 契约与应用

platform 维护 OpenAPI 3.1 并生成 Go 和 TypeScript 类型。客户端保存来源提交、契约版本、摘要和生成快照。工作区核对声明来源，并用 oasdiff 验证当前提供方与客户端契约的兼容性。兼容升级允许客户端滞后更新。

两个客户端使用提供方维护的同一组行为用例，覆盖能力、模块状态和错误响应。后续共享 SDK 包承载稳定的请求封装与生成类型，具体时机按接口规模安排。

Web 使用 Vue 3、TypeScript、Vite 和 Vue Router，类型与 ESLint 配置复用官方 create-vue 所采用的预设。stuhelper-admin 基于 Vben Admin v5.7.0 的 web-antd 应用，保留布局、主题、组件和 pnpm workspace。第三方源码与许可证保持可追溯，升级方法见[依赖维护](../guide/dependency-maintenance.md)。

两端的语言、格式和 RTL 规则由[国际化规格](../spec/internationalization.md)统一管理。页面只呈现实际接口结果，真实业务随模块接入。

## 工作区与验证

Mani 统一管理本地独立仓库。Go Workspace 按已检出的 Go 模块生成，各 Go 仓库保持独立构建。PR 集成使用当前候选和其他仓库最新 develop，配套修改显式选择相关 PR。每轮记录完整提交组合，支持固定候选与精确重放。部署版本由 ops 的版本 tag 组合维护。

验证覆盖依赖、能力降级、生命周期回退、远程恢复、身份拒绝、契约兼容、客户端共用用例和八语言浏览器联调。持久化、事件、真实会话和业务数据迁移在对应实现中增加专门验收。
