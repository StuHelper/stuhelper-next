# 课程目录与评课社区实施

## 当前范围

catalog 表示课程目录模块，reviews 表示课程评价与导师评论模块。业务规格已确认，社区、课程主页、教师主页、讨论、个人内容和管理页面已在任务分支实现。本轮补齐三个模块的目录运营、公开标签和审核复核能力。模块清单保留 in-progress，正式组合验收和运行交付仍未完成。

课程列表按长期课程去重，支持学校、开课学院、课程类别与性质，不展示或筛选学期。课程评价保存所选学期，任课教师候选来自本人该课程、该学期的可信选课记录。

| 模块 | 已实现 |
| --- | --- |
| catalog | 目录对象与摘要、批量引用、开课与教学班、导入差异预览、人工更正、合并与停用、本人选课 |
| reviews | 五维评课、导师评论、公开标签与任课教师实名、草稿与撤回、归属更正、展示配置和版本记录 |
| moderation | 发布检查、举报与作者申请、规则继承、复核、任务筛选与历史、批量预览、决定与失败重试 |
| platform | 无外部依赖的动作资格求值，缺失事实和不满足条件分别返回 |
| backend | 三个独立运行身份、公开接口装配、HTTP 路由、审核工作循环与隔离联调 |
| Web | 社区首页、课程与教师主页、开课与教学班、评价筛选、统计范围、讨论、个人内容和八语言界面 |
| stuhelper-admin | 目录合并、停用与导入，审核复核、批量处置、归属更正、优质认定及展示配置 |

社区入口为 `/community`，课程与教师目录为 `/courses`、`/teachers`，个人内容为 `/community/me`。课程主页提供分类、相关教师和历次开课，教师主页分别展示课程评价与导师评论。教学班页面仅展示本班教师及课表。

个人内容包括评价、草稿、课程收藏、投票和申请状态。普通草稿发布与草稿移除一起提交。版本冲突展示另一端保存的内容，由作者选择采用或保留本地输入。刷新讨论不会清空正在输入的回复。

管理端入口为 `/academic/reviews` 和 `/academic/catalog`。管理员可以查看待审原文，处理隐藏、恢复、删除、正文修改与讨论身份。页面分别展示决定已保存、已执行和投递失败，未知结果按原请求重试。

管理原文和列表使用 `reviews.moderate` 学校权限并记录查看审计。审核决定、策略与重试使用各自 `moderation` 权限。公开响应使用讨论内作者标识和逐项授权的公开标签；目录更正由 `catalog.maintain` 学校范围限制。

教师评分使用各课程等权平均，单门课评价多不会增加该课程权重。分课程统计与总体统计均返回展示等级和样本量，不显示精确均值。导师评论不参与评分。

## 输入、权限与状态

导入仅接受获准学校范围，每页最多 500 个对象及选课记录。学校数据不可用或导入失败时保留旧记录。已填写的人工更正不会被后续导入覆盖；同名对象不自动合并。

写入资格由服务端当前规则和可信事实决定。认证主体保留 issuer 与 subject。选课事实由 catalog 提供，校园资格与手机号通过应用 Authority 接口获取，缺少事实时不放宽规则。

重复写入使用同一幂等键返回原结果，同键不同内容拒绝。业务记录、审计和 outbox 在同一事务保存。审核先提交任务，再在事务外执行内容决定；重试保留决定 ID，旧内容修订不能覆盖新内容。

首次公开后的编辑窗口默认 5 分钟。撤回草稿保留 24 小时，重新发布保留首次时间、原回复和投票。过期读取立即拒绝，后台分批永久清理。普通未发布草稿独立保存，允许暂不填写学期和评分；发布时仍要求完整信息。

数据库迁移身份与运行身份分离。首次建库迁移和跨 schema 拒绝已验证；运行身份不能执行 DDL。HTTP 请求有大小和时间上限，列表单页最多 100 项，工作循环有批量上限与超时。

## 公开标签与任课教师

学生可以逐项公开真实姓名、性别、所属学院和已选课程。教师在其他讨论中可分别公开姓名、性别、教师认证标识和单位。客户端只发送所选键，实际值来自当前权威来源；未授权、过期或未知信息不能进入选项。

教师回复本人曾教授课程的评价时，任何学期都强制公开真实姓名及教师认证标识。服务端使用可信教师目录关联核对全部历史任课记录。缺少必需事实时拒绝发表，已发回复失去必需授权时停止对外展示和新增互动。

公开字段在读取时重新校验授权。正文记录只保存选择，不缓存姓名等属性值。教师使用独立回复资格，默认要求手机号与教师认证；本人曾授课程的评价允许教师查看全文。

## 目录与内容管理

目录合并先展示对象和当前修订，确认后沿用目标资料，保留源名称、旧链接和关联。目标别名容量不足时拒绝合并，避免丢失源名称。相同课程的开课与评价按规范 ID 合并查询。停用不删除历史，默认目录隐藏停用对象。

导入预览显示新增、更正、人工值保留、冲突及未关联记录。预览不写入业务记录，确认令牌绑定输入和当时数据。未知结果使用原请求重试，数据变化后要求重新预览。

已有评价的教师归属可按最新权威选课证据预览并更正，来源修订、原归属与决定留存。内容版本展示原文和处置说明，撤回内容的旧正文不能通过管理历史继续读取。

复核只允许内容作者发起，由另一名有复核权限的管理员处理。作者可以查看其他举报引发的决定，举报者私密理由和证据不会随反馈公开。任务支持时间、内容类型和对象筛选，批量最多 20 项并逐项反馈。

展示设置支持全局默认与学校覆盖，包含预览长度、比例和八语言评分文案。优质认定与撤销保存当前修订、理由及审计。通知和奖励由对应模块处理业务事件。

## 数据来源核对

私有适配任务已使用现有加密凭据核对开课学院、课程类别和性质。具体连接、学校表结构与字段映射仅保存在私有适配文档；公开测试使用合成数据。

字典中存在“新生研讨”“综合素养课”和通识分类。部分字典项没有教学班关联，不能据名称猜测归类。分类字典与课程归属需要分别核对，未知分类保留未知。

本轮未读取学生选课明细，真实学校数据未导入公共测试。已有选课记录只是服务接口的输入条件，公开排课不能替代个人选课证明。

## 外部集成与运行验收

真实身份、校园资格、手机号和公开昵称尚未在正式命令入口接线。未提供 Authority 时，只能访问无需身份的目录与匿名预览；带身份的写入明确返回依赖不可用。

identity、verification 和 profiles 分别提供正式登录、权威认证及公开昵称。学校抓取、定时同步、来源任务与重试属于共享接入能力。三个模块已提供数据导入、事实读取和事件接口，这些外部能力仍需按实际候选联调。

审核和导入 outbox 已保存。通知、搜索与奖励能力由所属模块订阅，尚未进行真实服务组合验收。当前不将外部模块建设列为三个业务模块的内部功能缺口。

备份与恢复、存量数据迁移、压力基准和真实账号验收尚未执行。资料与文件业务由对应任务实施，本轮只保留公开接口边界。

## 本地检查入口

新模块执行 `bash scripts/check-with-postgres.sh`，使用本任务独立的 PostgreSQL 18 集群。Web 执行 `pnpm run check`。管理端执行 `make check`。架构仓库中的 `playwright.academic.config.mjs` 使用 WEB_PATH 和 ADMIN_PATH 选择已构建候选。

跨仓依赖按 platform、catalog/moderation/reviews、backend/Web/stuhelper-admin、架构记录顺序评审。正式 backend 构建必须固定源码版本并使用 GOWORK=off，工作区联调不能替代独立构建。

## 候选接口更新

reviews 与 moderation 的候选接口升为 0.2.0。新增 disclosure_required 状态、appeal 类型和三个管理动作扩展原固定响应枚举。旧 0.1.0 消费者与新提供方不能混用，兼容性检查已明确识别这些变化。

该组合尚未发行。Web、管理端更新快照、生成类型、来源提交与摘要，backend 固定新的 Go 依赖。所有消费者与提供方一起验证和晋级，未关闭兼容检查或保留静默兼容分支。

## 候选组合与评审

workspace.lock.json 固定本轮源码组合。提供方接口快照已按实际 Git 提交核对，backend 使用固定 Go 依赖并通过独立构建。合并时先处理提供方，再处理消费者，最后更新架构记录。
