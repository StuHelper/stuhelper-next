# 框架实施状态

## 当前实现

platform 提供公共模块接口、依赖校验、能力降级、Fx 生命周期、HTTP 授权边界和可选远程连接。模块描述由其仓库的 `module.yaml` 生成，主仓库验证规格归属和公开能力一致性。

私有 backend 的统一候选已装配登录会话、公开昵称、学生认证、课程目录、评价、审核、资料、文件与存储。公共示例仍位于 platform 的 examples/server。campus-adapters 按配置启用，账务尚未接入。真实存储验证沿用存储主题。

通用存储已有独立库，实现多账号准入、三副本、两份发布门槛、恢复与清理，见[实施状态](storage-module.md)。media 已实现文件上传、批准、引用与下载，backend 固定依赖联调通过。贡献管理和 resources 资料业务已有候选实现，见[资料实施](resources.md)。生产环境未开放。

Web 与 stuhelper-admin 提供状态展示、错误恢复和八语言入口。Admin 另有存储运营页面，接口、权限和验收范围见[存储实施状态](storage-module.md)。国际化检查覆盖消息键、占位符、复数、数字、金额、日期、时区、相对时间和 RTL。

共享检查器、GitHub action、reusable workflow 与 Lefthook 预设已迁至 stuhelper-tooling。主仓库保留架构、Mani、工作区工具和应用联调。SSO 官方制品资料归 ops，后端身份实现归 backend。

## 统一业务组合验收

2026-10-29 的 business-acceptance 候选把认证与资料分支整合到同一 backend、Web 和管理端。会话绑定 issuer 与 subject，校园资格通过 verification 当前事实接口读取，署名昵称通过 profiles 公开接口读取。

| 流程 | 隔离验收结果 |
| --- | --- |
| 学生认证 | 手机拍照、提交材料、管理员批准、资格生效与删除申请批准通过 |
| 课程评价 | 当前学生资格、本人学期与教师、公开昵称、相同请求重放和冲突拒绝通过 |
| 导师评价 | 独立导师评论入口、匿名展示、手机号与学生资格检查通过 |
| 课程资料 | 上传真实文件字节、管理员审核、发布、三账号存储及内容一致下载通过 |
| 当前权限 | 无选课时不写评价，手机号解绑、学生资格删除、组织管理员撤权即时影响后续请求 |
| 故障与恢复 | 身份依赖故障后恢复、后端重启保留会话和资料、全部设备退出通过 |

浏览器直接调用正式 backend，数据库使用 PostgreSQL 18 和九个独立运行身份。OIDC/Casdoor 和 BHpan 边界使用隔离 TLS 协议服务，学校目录与本人选课使用合成数据通过管理接口导入。

业务流程脚本为 backend 的 scripts/business-acceptance.mjs，统一入口为 make check-business。结果包含 18 项流程检查、截图和源码提交。各仓必需检查另行执行；最终组合记录在 workspace.lock.json。

profiles 本轮建立本地独立仓库。正式 Go 构建使用 GOWORK=off，未发布的 profiles 提交通过本地文件型 module 源提供，脚本校验 go.mod 的精确提交。远端仓库与 CI 交付仍需完成。

真实 SSO 发行版本、学校同步、邮件与实名渠道、真实 BHpan 账号未参与本轮组合验收。生产发行、部署、存量数据迁移、备份恢复和容量测试尚未执行。头像、简介、个人主页和账号注销不在本轮已实现范围。
