# 框架实施状态

## 当前范围

platform 的运行时模块声明由架构清单生成，并在构建和联调时验证一致性。platform 提供模块注册、必需与可选依赖、能力级依赖、Fx 生命周期、HTTP 访问边界和远程服务连接。健康探测在后台执行，管理状态分别表达生命周期和当前健康状态。就绪接口按组合中的关键模块判断。

Web 与 stuhelper-admin 提供可运行的应用入口、服务状态与错误恢复。应用默认中文，支持中文、英文、法文、俄文、日文、韩文、西班牙文和阿拉伯文。国际化检查覆盖消息、占位符、复数、数字、金额、日期、时区、相对时间和 RTL。

架构仓库维护统一 Mani 清单、工具链、术语、规格映射、集成源码组合和契约来源校验。共享工程工具包通过同一发行 tag 供八个模块仓库使用，工作区检查验证版本与来源。各代码仓库保留独立检查，并调用可复用工作流验证跨仓候选。当前客户端复用提供方维护的行为用例，后续共享 SDK 包按接口规模安排。

## 验证范围

| 范围 | 检查入口 |
| --- | --- |
| 架构与文档 | 根仓库 `make check` |
| platform | 独立 `make check`，包括 race、契约、生成和导入边界 |
| Web | 独立 `make check`，包括国际化与客户端用例 |
| stuhelper-admin | 独立 `make check`，包括国际化、公共组件与客户端用例 |
| 跨仓组合 | 工作区契约检查、工具链检查和八语言浏览器联调 |

CI 同时验证 push 与 PR，按完整差异选择集成，并由 Repository checks 汇总必需结果。源码组合、工具版本和共享工程工具版本继续由现有清单管理。本地 hooks 保留真实 Git 历史，检查暂存区或实际推送提交。

本次 CI 调整已完成本地验证：仓库检查、actionlint、27 项工作区与 CI/hook 测试、22 项共享 Node 工具测试，以及 2 项原生 Mani 失败退出测试通过。真实 Git fixture 验证了错误暂存内容被拒绝和本地推送前的完整检查。

锁文件指定的三个模块组合已通过 Go race/构建、Web 24 项测试、stuhelper-admin 333 项测试和八语言桌面/移动端 80 项浏览器测试。测试服务已停止，模块源码保持干净。

本地缓存实测约为仓库工具 374 MiB、前端依赖 1418 MiB、Go 614 MiB，低于各自上传上限。GitHub 的实际取消、缓存上传与命中尚待远端验证。模块仓库仍引用已发行的工具 tag，本次可复用 workflow 改动需随后续版本发行供模块采用。正式部署版本由 ops 单独维护。

## 剩余实施

业务 API、数据库迁移、真实身份接入、校园数据导入、评价、文件、账务和查询服务仍按各自规格实施。评价资格使用选课记录，教师选项来自本人任课记录；删除与撤回行为以[评价规格](../spec/academic-content.md)为准。

首次持久化业务写入同时落实幂等、数据访问角色和必要事件。首次身份信息查询同时落实查看审计。真实账号、镜像发行、SSO 生产迁移和生产部署按对应任务验收。
