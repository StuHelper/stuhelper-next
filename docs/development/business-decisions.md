# 业务确认结果与延期事项

## 本轮结果

旧业务抽取中的产品选择已经逐项确认，或由项目负责人明确延期。当前没有等待回答的业务问题。数值参数按照已确认规则由后台配置，不再将每一个上线数值列成未定产品决策。

## 已确认主题

| 主题 | 确认结果 | 维护位置 |
| --- | --- | --- |
| 课程、教师与导师 | 课程五维评价，教师评分先算课程均分再对课程等权平均，导师仅文字评论 | [评价规格](../spec/academic-content.md) |
| 身份与内容修改 | 默认匿名、可昵称署名，同一讨论身份一致，可配置短时撤回，管理员处理其他修改与删除 | [评价规格](../spec/academic-content.md) |
| 草稿与举报 | 多份跨端草稿，冲突选择版本，处理中举报可补证据，结案后可因新事实再举报 | [评价规格](../spec/academic-content.md) |
| 内容运营 | 可配置审核、分类、敏感词、复核与批量预览，有效与优质内容有明确认定方式 | [内容管理](../spec/content-management.md) |
| 账号与个人主页 | 学校与徽章默认公开可调整，绑定唯一归属，注销只处理本应用 | [个人中心](../spec/personal-center.md) |
| 学生资格与实名 | 完整规则私有维护，公共模块只使用必要资格结论 | [认证对接](../spec/student-verification.md) |
| 动作资格 | 全站默认和授权范围覆盖，可收紧或放宽，后续操作生效并保留既有记录 | [资格配置](../spec/action-eligibility.md) |
| 资料与作品许可 | 原创/转载简化填写，版本先审，保留文件原名，目录只打包有权内容 | [资料共享](../spec/resource-sharing.md) |
| 账户、会员与交易 | 已确认规则移入私有账务模块，金额与期限按配置管理 | [账务对接](../spec/wallet-and-points.md) |
| 群管理 | 两种认证准入及独立动态口令，名片、黑名单、消息规则、聊天工作台与订阅均保留 | [QQ 群服务](../spec/qq-group-services.md) |
| 信息查询 | 按范围与字段分层，机器人按请求人权限返回，批量与导出独立授权 | [信息查询](../spec/information-query.md) |
| 娱乐 | 骰子与自助禁言按群配置，主动参与，管理员可提前解除 | [娱乐功能](../spec/bot-entertainment.md) |
| 目录与课表 | 人工确认字段优先，合并保留关联，个人课表可手改与导出 | [目录维护](../spec/catalog-operations.md)、[课表](../spec/my-courses.md) |
| 热度与趋势 | 指标权重、窗口、样本量可配置，教师评分与导师评论分开 | [发现与统计](../spec/discovery-and-statistics.md) |
| 通知 | 站内优先，互动可关闭聚合，外部渠道用户选择，免打扰延后外部推送 | [通知](../spec/notifications.md) |
| 开放平台 | 应用审批、逐项授权、最小字段、撤回与第三方删除义务 | [开放平台](../spec/open-platform.md) |
| 存储贡献 | 实际接入服务商，退出先迁走文件，自愿上榜，公开透明度 | [存储贡献](../spec/storage-contribution.md) |
| 管理后台 | 可配置角色模板、对象范围、独立敏感权限及并发配置提示 | [管理操作](../spec/admin-operations.md) |
| 客户端与迁移 | 当前仅 Web/Admin；保留 SSO 与学生认证数据，不迁移独立实名及其他旧业务数据 | [重写路线](rewrite-roadmap.md) |
| 品牌与产品边界 | 沿用 StuHelper 和纸飞机品牌，不建设作业实验系统或学校教务写入功能 | [业务范围](../design/business-scope.md) |
| 仓库边界 | 按业务模块拆仓，认证、学校适配、账务与生产配置私有 | [多仓库设计](../design/module-repositories.md) |

## 项目负责人明确延期的事项

| 事项 | 当前处理 |
| --- | --- |
| 社交动态、分区、关注、私信与站内群聊 | 独立延期，评价自身互动继续保留 |
| 微信小程序、Android、iOS、HarmonyOS | 暂时搁置，保留参考设计 |
| 贡献存储承载受限资料 | 延期，首期仅存可公开分发资料 |
| 开放平台商业收费 | 独立延期，接入与授权业务继续保留 |
| 认证服务商与账务后续渠道细节 | 在私有模块保留明确延期记录 |
| 最终面向用户的完整作品授权协议 | 上线前单独定稿，本轮保留业务原则与提示要求 |
| 首期范围以外的离线下载 | 延期，先缓存公开目录、本人课表与草稿 |

## 后续实现

接口字段、具体配置值、原型布局、性能目标和生产切换仍属于后续实现工作。文档中的 Accepted 表示业务决定已经确认，不表示服务已经实现或部署。完整来源分类和检查证据见[迁移覆盖](business-migration-coverage.md)与[整理记录](business-design-extraction.md)。
