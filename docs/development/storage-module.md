库在失败重登时清除原会话。重新授权应使用隔离的新客户端验证，成功后切换凭据修订，不能在仍服务任务的客户端上尝试登录并破坏原会话。供应商授权状态与平台是否允许新写分别处理。

固定提交的 `auth.go` 在一个 SSO 登录回调分支调用 `refreshToken`，随后读取 token 并查询文档库验证会话；这不证明后台可持续续期。`client.go` 仅持有内存会话，未提供持久化或公开续期入口；`Close` 只清除本地状态，不等于供应商撤销授权。

backend 已实现加密托管凭据及重启后重新登录，随后由连接层恢复同一账号与专用根。三个真实账号已通过此恢复路径；失败与并发用例另有夹具验证。此路径不持久保存 token，也不声称原会话自动续期，真实跨期验收仍未完成。

## BHpan 持续授权验证方案

持续可用要求同时满足用户或平台仍同意使用、供应商授权仍有效、当前操作权限及实例准入仍有效。登录成功只验证一个时点，不能证明未来可用；平台自有和用户贡献账号均须验证，贡献同意与供应商令牌也不能互相代替。

以下计划已完成短时观测、凭据重登、跨进程恢复、平台停用与续授验证，供应商真实到期和无密码续期仍未执行。学校临时会话、BHpan 访问令牌与续期材料分别核实；不能因路径名含 `refreshToken` 就认定支持标准续期或永久续期。

长期存储托管允许在账号拥有者明确授权的期限内保存所需凭据，具体边界见[数据保留规则](../spec/data-retention.md)。一次性学校认证的十五分钟限制不套用于长期托管；依赖学校密码的 BHpan 重新登录须有明确用途授权。

| 验证项 | 操作与证据 |
| --- | --- |
| 授权材料与权限 | 分别记录 SSO 和本地账号所需材料类型、供应商声明期限及可用操作；核实是否存在专用令牌和目录级权限，不保存原始响应到日志 |
| 闲置与活跃到期 | 在互不干扰的独立试次中比较不访问和低频访问；闲置会话仅在观察终点探测，避免探测本身续命。记录最后成功、首次失败与错误类型 |
| 无密码续期 | 跨过实际访问令牌期限后，使用已核验机制续期并读取受保护资源；确认新材料替换、旧材料行为及重复续期，不以 HTTP 200 或令牌字符串变化认定成功 |
| 凭据重新登录 | 用获准托管的账号凭据创建新客户端，确认同一稳定账号、专用根与受保护资源后切换；遇到验证码或密码失效进入待重新授权，不无限重试 |
| 重启与并发 | 保管规则明确后验证最小材料恢复；同账号并发续期只执行一次，轮换失败或旧进程回执不得覆盖新凭据修订 |
| 撤销与重新授权 | 隔离测试供应商支持的撤权、会话到期及 StuHelper 停用；分别验证停止新请求、在途结果隔离和重新授权，不把本地 Close 当作远端撤权 |
| 操作范围与内容 | 登录和续期后读取专用根、容量及无敏感测试对象；后续写权限演练只在专用根创建、回读校验及删除小文件，不触及个人文件 |
| 故障分类 | 区分 401、403、登录页伪成功、限流、网络超时和验证码；超时不直接判定撤权，权限拒绝不触发反复重登，需交互时进入待重新授权 |

按供应商声明及实测期限设计跨期观察；声明不清时可先观察三十分钟、两小时和二十四小时，再做三至七天稳定性试验。这些窗口是测试建议，不是凭据保存上限、令牌寿命或长期可用承诺。验证记录区分原会话续期和使用托管凭据重新登录。

真实验证只使用获准测试账号和隔离根。改密、注销其他设备等会影响正常使用的动作另行安排。短时文件演练结束后清理材料；长期观测使用明确期限的临时密文托管，期限与供应商会话寿命分别记录，未观测到真实到期时不能声称续期成功。

结论按实际证据分为可自动续期、可用托管凭据重新登录、需要人工重新授权、无法满足持续接入四类。自动恢复需重复验证、获准材料可恢复、停用可阻止后续使用且故障不会无限重登；需要人工授权时单独评审运营可接受性。

运行时由凭据管理负责材料保管与轮换，adapter 只执行经验证的供应商协议，存储核心消费授权状态及修订。失效后停止依赖该凭据的操作与新放置，从其他健康副本读取或修复；网络故障退避探测，禁止无限重试续期。

凭据库按用途、修订与期限校验，密钥和密文分开保存。到期停止使用并按分钟清除材料，撤销保留拒绝标记；首次建根前保存唯一意图，响应丢失时只核对原目录。离线命令提供托管管理；真实测试材料仅在临时密文库中保存，清理后销毁，生产托管未配置。

Next 的 Casdoor 尚未部署或配置，腾讯云仍运行旧 SSO。本轮以受控 TLS 响应验证官方令牌检查协议，以私有授权文件表达明确运营权限；未连接或修改旧 SSO，也未实现新的应用登录会话和业务账号映射。

同进程提供 HTTP 时，后台 worker 数必须小于总传输并发，至少为前台保留一个传输名额；无 HTTP 的 worker 也不能超出总传输并发。该约束在装配时检查，各进程的预算仍需部署配置分别分配。

## 本轮验证

2026-10-26，storage 在 GOWORK=off 下通过生成契约、真实 PostgreSQL、race、vet、构建、文档和工作流本地检查。测试使用独立 schema 及受限运行身份，数据库自行建立并清理；普通检查缺少测试数据库时直接失败。

执行器测试覆盖队列仅容纳一个任务时逐步补齐与删除、停止后拒绝新传输、取消在途读取及服务重建后的副本恢复。子进程验证活动暂存目录互斥，以及未清理退出后的残留回收。耗尽重试的任务不会被常规维护重新激活。

新增真实演练永久删除一份账本内测试文件，由独立 storage-worker 自动发现、清理和重建。远端标识与写入意图均变化，重新达到三份健康副本，内容与容量统计通过校验。换代后已失效的旧任务正常结束，不再误报为待处理阻塞。

运维 API 展示实例容量、对象缺口及失败任务分页；托管层补充退避、授权到期和待重新授权。会话失效按可重试不可用处理，真正撤权继续停止任务。worker 每十秒替换私有状态文件，命令区分异常、过期和停止，不读取或暴露供应商凭据。

backend 在独立 PostgreSQL 下通过运行身份检查、HTTP 401/403/200、后台补齐三副本、配置化 API/worker 启停及凭据库释放，并通过 race、vet 和正式构建。常规认证与供应商测试使用显式夹具，真实 BHpan 另行验收，两类证据分别记录。

新增验证覆盖凭据篡改、并发轮换、用途、到期清理与撤销恢复，同账号登录互斥、会话失效退避，以及未知建根结果不重发。身份检查拒绝错误 issuer/audience、过期与非访问令牌，并在撤权或跨学校范围时拒绝访问。

三个获准账号已通过真实三副本演练：单份拒绝引用发布，两份允许建立业务引用并下载，三份达到就绪状态。测试仅使用随机专用根和小型合成文件；普通文件生命周期、稳定账号标识、完整回读及 SHA-256 校验均有真实供应商证据。

验收将元数据备份恢复到另一套隔离数据库，再由新进程读取同一临时密文库、重新登录并核验三个原根及副本。随后撤销平台托管授权或停用实例，验证降为两份、一份和零份，零份停止交付；续授后恢复三份。生产备份与撤销记录恢复仍待验收。

已结束的短时演练完成测试文件永久删除；清理登录偶发失败时保留材料，单独重跑确认根及回收站内容消失，再销毁本机材料。长期观测的专用文件保留至本次观测结束，随后执行同样清理。普通 CI 只编译真实验收入口，不登录测试账号。

长期验收入口已实现独立 systemd 用户服务及二十四小时上限：一个账号停用并保持会话闲置，另两个账号由 worker 使用。期间两份副本及一份缺口是预期条件，不能为消除提示而访问闲置账号。终点探测、恢复三份、永久清理与脱敏结果记录由验收程序完成。

长期运行使用 WSL 私有密文库和独立密钥，测试授权期限为观测时长加两小时。运行目录限 8 MiB，二进制与数据库目录限 384 MiB，状态单文件限 1 MiB；到期或结束清理。观测中断、网络失败和会话仍有效分别记录，不作为真实到期后恢复通过的证据。

初始和闲置十二分钟后的刷新请求均返回 200，token 未变，受保护读取成功。cookie 未声明寿命；本轮已验证凭据重登后的跨进程恢复，仍未观察到真实到期或证明无密码续期，因此持续贡献保持关闭。密码、token 和个人目录信息未进入仓库或测试记录。
