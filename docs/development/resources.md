# 学习资料实施

## 当前范围

resources 已有独立公开仓库和候选实现，管理统一分类、配置字段、课程关联、版本、审核、访问授权、申请和目录打包。文件内容由 media 与 storage 保存，课程对象通过 catalog 校验，审核由 moderation 执行。

Web 与 stuhelper-admin 的资料入口为 /resources，课程主页提供关联入口。用户可筛选分类字段、查看年份分组、上传原文件、维护本人资料、提交申请和下载分包。管理员配置分类与目录、处理审核、授予或撤回访问权。

| 组件 | 当前实现 |
| --- | --- |
| resources | PostgreSQL 独立运行身份、分类修订、版本快照、幂等与事务、审核任务、当前访问权、目录与下载包 |
| media | 文件上传会话、本人文件清单、引用发布、独立审核读取、完整下载和 ZIP 清单 |
| storage | 原三副本目标与两副本发布条件，另设独立审核读取权限，不改变发布状态 |
| moderation | resource 内容种类、学校范围队列、审核决定、申请复核与失败重试 |
| backend | 课程、审核、资料和媒体公开接口装配，独立服务主体及共享身份与资格端口 |
| Web | 配置分类与字段、课程关联、上传、资料详情、申请列表、目录与多包下载 |
| stuhelper-admin | 分类字段与选项、目录、资料状态、单独授权、审核文件及决定执行状态 |

## 配置与业务边界

初始课件、往年题、教材和习题保存在数据库，管理员可以修改。分类使用稳定 ID，字段支持文本、整数与选项。年份只是可筛选和分组的整数配置，未知值保留为空，页面不按分类名称分支。

资料版本保存分类修订快照。修改分类后，新提交检查当前配置，既有已发布版本保留原说明。更正或新版本待审时继续交付旧发布版，审核和异步文件发布成功后再切换。

上传默认要求有效校园资格和绑定手机号。公开下载要求有效校园资格，受限下载另查当前单独授权或外部权益。管理员例外限制在本人学校范围，全站分类管理使用独立权限。

审核员通过独立权限读取待审文件，读取不激活普通下载引用。普通下架保留已有购买权益的交付判定，安全停用阻止全部下载。申请列表只返回本人的回执，详情从 moderation 读取当前处理结果。

每次上传保存媒体会话，失败先查实际状态。前端对结果未知的写入保留原请求内容和幂等键，取消需服务端确认。ZIP 只包含当前有权访问的资料，列出全部分包，下载前及输出前重新检查权限。

私有 backend 配置固定学校、公开或受限目的与 media profile 的对应关系。启动时核对文件大小、允许类型、学校与保护范围，并确认资料分包限制不超过 media 上限。后台任务和包清理均有批量、超时与重试上限。

## 实际验证

验证运行于 Ubuntu-26.04 WSL，使用声明的 Go、Node.js 与 pnpm 版本。数据库测试建立独立 PostgreSQL 18 集群，运行身份分别限定在 catalog、moderation、resources、media 与 storage 的 schema，结束后清理测试集群。

resources 的生成一致性、11 组登记场景、race、vet、构建与文档检查通过。storage 的 34 组场景与 media 的 12 组场景检查通过，新增独立审核读取不改变普通下载的发布条件。

backend 已验证真实 PostgreSQL 下的课程关联、文件上传、审核前读取、审核决定、媒体发布、完整下载、ZIP、下架申请和权限撤销。错误学校、超限配置、普通用户授权、服务主体越权与资格服务失效均有拒绝测试。

Web 与 Admin 各有九项传输单元测试和 80 项资料浏览器用例。浏览器覆盖八语言与桌面、移动视口，检查配置字段、重试、上传、权限撤销、申请、目录及全部分包。浏览器使用明确 HTTP 夹具，文件与数据库链路由 backend 集成测试验证。

完整应用检查通过：Web 59 项单元测试与 192 项浏览器用例，Admin 376 项单元测试与 176 项浏览器用例。另有 80 项公共框架和 352 项课程社区浏览器用例通过，既有课程、存储与资料页面使用同一候选客户端。

Next 的 20 模块架构、18 项脚本测试、文档、工作流、13 个检出目录的工具链及契约来源检查通过。[固定候选](../../workspace.lock.json)包含 12 个实际参与的仓库，均为已提交状态。远端 CI 结果随配套草稿 PR 更新。

中文桌面及阿拉伯语移动截图已检查。根据截图修正 Web 控件拉伸、跳转链接隐藏及 Admin 深色主题对比度。其他语言已检查键、参数、布局与交互，语义仍需母语审阅。

## 交付与剩余范围

本轮交付为候选源码与草稿 PR。课程、存储和资料分别维护自己的数据和接口，真实 SSO、校园资格供应方、生产数据导入、运行环境容量与备份恢复仍按对应环境验收，当前没有合并、发行或部署。

账务尚未接入时，购买与会员入口关闭；单独授权可用。贡献奖励、在线阅读器、个性化标记及应用层加密继续按既有决定延期。正式作品授权条款由负责人上线前定稿。

相同文件内容去重和本人免上传已有候选实现。media 检查当前来源权限、用途配置和已完成版本，保留独立审核。storage 按服务身份、保护要求、摘要、长度和副本策略共用物理内容，引用释放及迁移有持久化记录。

跨用户只提交哈希仍需实际上传，完整校验后可以共用同范围副本。两端页面支持免上传提示和处理中重试。保护要求不同的内容分组单独保存，迁移保留已校验来源。旧版对象保留原身份，没有执行历史数据批量合并。

新增数据库回归覆盖并发上传、来源权限与配置变化、独立审核、响应丢失、重启、取消、最后引用清理和迁移中删除。最后一个引用释放时，物理删除完成后才报告清理完成。
