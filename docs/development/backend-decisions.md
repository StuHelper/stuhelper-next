# 后端候选实施状态

## 当前实现

教师认证、内容准入、本人记录、资料访问、个人主页、注销、收藏与开放平台候选已实现、待合并。favorites 与 open-platform 为独立模块，各自拥有仓库、数据和接口。实际源码组合由 workspace.lock.json 记录，正式后端依赖由 backend/go.mod 固定。

| 模块 | 当前能力 |
| --- | --- |
| verification | 教师本人申请、补充材料、人工审核与多档案绑定；档案只能属于一个账号；本人实名字段由服务端脱敏 |
| catalog、reviews | 当前内容准入、本人记录名称与经过验证的草稿关联；公共详情继续执行当前授权 |
| moderation | 新举报要求内容准入；认证失效后仍可补充本人处理中举报的证据，只返回本人回执 |
| resources | 预览与下载同权；投诉只需登录，提交时通过准入才保存标题快照；购买延期 |
| profiles | 昵称 20 和简介 120 个 Unicode 码点；主页展示开关、7 天注销冷静期与可恢复处理进度 |
| favorites | 课程、教师与资料收藏，以及收藏夹管理 |
| open-platform | 应用审批、逐项同意、PKCE、短期令牌、撤回和通知反馈 |
| billing | 积分与 Ivory 分账、余额和明细、奖励与追回、充值、购买积分、退款和注销结清；真实支付未接入 |
| platform | 模块生命周期、公共资格规则与安装历史；独立 PostgreSQL schema 与运行身份，短时缓存和审计清理 |

学校、认证徽章、学院、署名评价和资料默认公开，年级默认关闭。姓名显示末字，证件号显示首尾位，星号数量等于遮住的码点数。姓名少于 2 个码点或证件号少于 3 个码点时拒绝提交。

## 验证与剩余工作

账务及 backend 组合数据库检查已通过，最终候选组合等待 PR CI。数据库验证使用隔离 PostgreSQL 和模块运行身份，正式构建设置 GOWORK=off。模块场景与测试函数登记在 architecture/modules.yaml。

QQ 绑定状态与绑定状态和号码分别授权。公开主页仅对可信代理解析转发地址，按客户端地址使用进程内单一限流器，多实例各自计数。可信 QQ 来源尚未接入，返回 503。真实支付、真实账号、发行与部署未验收。会员交易、会员权益及资料购买未提供。

Web/Admin 需要同步目录准入、profiles、本人记录、收藏夹、细粒度授权与账务客户端。公共集成的客户端契约差异仍待处理，保持必需检查开启。
